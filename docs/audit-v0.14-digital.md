# v0.14.0 GPIO, clock, timer and time-driver comparison

The following table accounts for every existing file in these driver modules.
It separates corrected defects, preserved CW contracts and omitted upstream API
features. Comparison uses actual Embassy commit
[b12a6d9efcd2711037abca1b63a661a9ef726444](https://github.com/embassy-rs/embassy/tree/b12a6d9efcd2711037abca1b63a661a9ef726444/embassy-stm32/src),
the [embassy-time-driver 0.2.2 contract](https://docs.rs/embassy-time-driver/0.2.2/embassy_time_driver/trait.Driver.html),
[L012 RM1.4](https://www.whxy.com/uploads/files/20260603/CW32L012_UserManual_CN_V1.4.pdf)
and [F030 RM2.5](https://www.whxy.com/uploads/files/20240920/CW32x030_UserManual_CN_V2.5.pdf).

## Corrections

- Time before initialization returns zero without MMIO; pre-init alarms survive
  initialization and are rearmed after unpend.
- A full 16-slot time queue wakes a displaced task to retry rather than panicking.
  Such retries can be early; deadline expiry itself still uses the full timestamp.
- Waker clone, unused drop, displaced wake and due wake occur outside the driver
  state's borrow/critical section, including reentrant RawWaker callbacks.
- L012 specialized PWM and time startup gate master trigger outputs while issuing
  preload UG. F030 specialized PWM construction and disabled-output duty commit
  gate the timer-master route as well as ADC triggering. Prior route settings,
  output protection and explicit rearm behavior are retained.

## Verification boundary

Fresh source/PAC probes cover the new startup and callback paths, GPIO event
races, eight mixed/standalone timer combinations, PWM arithmetic, RCC validation
and protection sequences. Ownership and Binding misuse are compile-negative
checks. Details and counts are in [validation](validation-v0.14.0.md).

These checks establish the software sequence under the stated register models.
They do not measure electrical glitches, actual preload/filter latency, clock
accuracy, silicon flag synchronization or the complete power-stage response.

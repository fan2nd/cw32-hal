采样检查覆盖 129600 组电压/角度/母线组合和 200000 组边界随机输入；两个窗口、顺序、截止点和整数范围均成立。跨 PWM 帧的电压积分与逐计数积分参照一致（舍入误差小于 2 mV）。零指令长时平均电压约 [0,−0.5] mV，验证补偿没有固定方向直流偏置；这不证明瞬时电流安全。

采用最后的 3.35 Ω/875 µH 模型、实际最小窗口调制、两帧流水线和约 12.21 mA ADC 量化，在假定的开关/PMSM机械模型中：

- 8/12/16 V 及 12 V 较大惯量的空载场景均能完成 OpenLoop→Blend→ClosedLoop，收敛到约 25 电气 Hz；最大物理相电流分别约 255/260/295/264 mA。
- 同一 12 V 轨迹中，未校正的错时重建 RMS/峰值误差约 32.66/120.4 mA；时间预测后约 4.10/14.7 mA。
- 大负载场景不能达到资格，超时关断；没有扩大角度门槛强行接管。
- 早期错误 R 模型造成的假反电势、低 L 电机的实际峰值先于软件采样超限等现象已识别；软件资格检查不能修复参数或逆变器模型误差。错误参数不能当作已可靠无感运行。

上述机械模型中的极对数、磁链、惯量和负载都是试验假设，不是用户电机事实。模拟不包含实板驱动传播、实际死区电压、模拟建立、ADC 误差、总线等待或中断实时性，因此不能推导实板启动成功率、额定性能或安全等级。

## 存储与时间预算

当前截止点诊断版构建：text=19804 B、data=588 B、bss=1304 B，即约 20392 B Flash 和 1892 B 静态 RAM。CW32L012C8 链接区为 64 KiB Flash / 8 KiB RAM，剩余 RAM 还要容纳运行栈，未测栈高水位。

10 kHz 每帧只有 9600 个 96 MHz CPU tick。调制最大比较值限制为 4800，最晚第二样本服务时刻为 4762，控制截止点为 9000，预留约 44.1 µs。早期 update 服务截止为 CNT=700。第一样本的读取容差仅 128 tick（约 1.33 µs），必须验证所有短临界区与 ISR 的实际最坏延迟。

纯控制/采样 ARM 汇编没有浮点或 64 位除法调用；速度诊断使用少量 64 位乘法，整个程序的启动时钟校验仍可能使用 64 位运算。除法调用点数量不是一次控制迭代的周期数。尚无 Cortex-M0+ 实测 WCET，运行时 deadline/漏采样检测只负责失败关断，不构成性能证明。

`max_control_ticks` / `max_update_ticks` 为运行时辅助观察，未覆盖完整异常入口/退出。实时采样期间没有日志调用；首故障关闭桥臂、停止 ATIM 触发并禁用高频 IRQ 后，I/O 线程才打印冻结快照。waker 的 clone/drop/wake 位于短临界区之外。

## 按键前 13 号故障的定向修改

本次基线逐文件 Git blob 校验与 `f40bab5df52433d8faa7ceffafea73ce8c777b60` 一致。用户日志的两个接受时刻 2802/3405 均位于原有窗口，最近 ADC 尾部计数 5814 低于 9000；frame=1 与随后 reload 路径超时相符，但旧日志没有记录 Timing 检查点，不能确定究竟是入口、预载、解锁末尾或 UIF 条件。

ARM release 汇编证实原待机 reload 路径仍搬运三份 28 字节 Plan、重建 Off 计划并清调制器状态。现将 previous=active 移到第二样本消费旧 previous 之后，与 previous_bus_mv 同步保留；调制器复位也在 ADC 非 FOC 分支进行；reload 只在待机转换时覆盖非 Off 的 pending。启动/停止命令仍在 reload 生效，active/staged/pending 的硬件延迟不变。所有实际故障关断之后立即返回，不再在冻结快照后继续执行预载、ADC 启动或控制计算。

新增独立 TimingTrace：site=1/2/3/4/5 分别指出 reload 入口、预载完成、解锁末尾、ADC 控制末尾、控制帧间隔；记录起点、实际计数、原截止点、UIF、样本数。完整字段只在错误分支保存，RTT 仍仅在安全停机后的普通线程输出。700/9000/128 tick 限制保持不变，并显式检测 reload 路径计数回绕。

本次 ARM `thumbv6m-none-eabi` release `-D warnings`、格式检查及既有 27 项外部测试均通过。新增 3 项外部模型测试覆盖 20000 帧、超过 100 次启停、变化的母线/调制值、前后帧积分等价、漏采样/未准备计划的提前关断及时间边界。模型使用真实 sampling/config 源码，但不是硬件 ISR、总线等待或实测 WCET 测试。01–06、共享 HAL、控制参数和 CI 均无本次改动；没有烧录。尚须新台架计数验证本次优化后是否满足原时限。

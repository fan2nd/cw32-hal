## 最终参数来源

用户确认 R0 实物为 10 mΩ。电机 R=6.7 Ω、静态 L=1.75 mH 是任意两根引线间的测量，已在配置中保留原始值，并用平衡等效星形相模型 3.35 Ω/875 µH。没有宣称已测到 Ld/Lq、极对数、反电势常数、惯量或额定电流。

按 50 Hz 名义带宽给定电流 PI（Kp Q15=9008、每帧 Ki Q15=3449），对齐/启动/运行电流限值为 150/200/250 mA，软件跳闸 750 mA。这是低电流实验配置，不能代替电机/功率器件额定值或外部硬件保护。按用户要求移除额外功率/参数确认常量；普通构建上电先校准并等待按键，按下后可执行功率启动和有资格的无感接管。所有实际保护和资格检查保留。

## 外部数学检查（不随源码交付）

共 21 项主机检查通过：12 项控制回归 + 9 项采样/调制检查。包括所有 65536 个角度的查表精度、Clarke/Park、限幅和 PI 反积分饱和、启动/停止/故障锁存、零反电势不接管、有资格接管与失锁、实际 dt 算法，以及全部六种电流重建相序。

采样检查覆盖 129600 组电压/角度/母线组合和 200000 组边界随机输入；两个窗口、顺序、截止点和整数范围均成立。跨 PWM 帧的电压积分与逐计数积分参照一致（舍入误差小于 2 mV）。零指令长时平均电压约 [0,−0.5] mV，验证补偿没有固定方向直流偏置；这不证明瞬时电流安全。

采用最后的 3.35 Ω/875 µH 模型、实际最小窗口调制、两帧流水线和约 12.21 mA ADC 量化，在假定的开关/PMSM机械模型中：

- 8/12/16 V 及 12 V 较大惯量的空载场景均能完成 OpenLoop→Blend→ClosedLoop，收敛到约 25 电气 Hz；最大物理相电流分别约 255/260/295/264 mA。
- 同一 12 V 轨迹中，未校正的错时重建 RMS/峰值误差约 32.66/120.4 mA；时间预测后约 4.10/14.7 mA。
- 大负载场景不能达到资格，超时关断；没有扩大角度门槛强行接管。
- 早期错误 R 模型造成的假反电势、低 L 电机的实际峰值先于软件采样超限等现象已识别；软件资格检查不能修复参数或逆变器模型误差。错误参数不能当作已可靠无感运行。

上述机械模型中的极对数、磁链、惯量和负载都是试验假设，不是用户电机事实。模拟不包含实板驱动传播、实际死区电压、模拟建立、ADC 误差、总线等待或中断实时性，因此不能推导实板启动成功率、额定性能或安全等级。

## 存储与时间预算

最终普通构建：text=17216 B、data=484 B、bss=212 B，即约 17700 B Flash 和 696 B 静态 RAM。CW32L012C8 链接区为 64 KiB Flash / 8 KiB RAM，剩余 RAM 还要容纳运行栈，未测栈高水位。

10 kHz 每帧只有 9600 个 96 MHz CPU tick。调制最大比较值限制为 4800，最晚第二样本服务时刻为 4762，控制截止点为 9000，预留约 44.1 µs。早期 update 服务截止为 CNT=700。第一样本的读取容差仅 128 tick（约 1.33 µs），必须验证所有短临界区与 ISR 的实际最坏延迟。

纯控制/采样 ARM 汇编没有浮点或 64 位除法调用；速度诊断使用少量 64 位乘法，整个程序的启动时钟校验仍可能使用 64 位运算。除法调用点数量不是一次控制迭代的周期数。尚无 Cortex-M0+ 实测 WCET，运行时 deadline/漏采样检测只负责失败关断，不构成性能证明。

`max_control_ticks` / `max_update_ticks` 为运行时辅助观察，未覆盖完整异常入口/退出。无 RTT 后不再有整条日志的 PRIMASK 区；线程只读原子状态，waker 的 clone/drop/wake 位于短临界区之外。

## 寄存器审核依据与最小 HAL 变更

依据 [CW32L012 RM1.4](https://www.whxy.com/uploads/files/20260603/CW32L012_UserManual_CN_V1.4.pdf)：

- §17.3.1.5、17.3.1.10：更新、重复计数和各通道比较预载。
- §17.10.2（印刷页 372–373）：MMS2=11010，OC4REFC 上升或 OC5REFC 上升。
- §17.3 / §17.10（死区见印刷页 349–350、403）的 PWM、CCER、BDTR、DTR2 定义：互补极性、死区、OSSI/OSSR、MOE 和 AOE。
- §25.4.2：ADC 采样+15 周期转换、最高时钟和吞吐率约束。
- §25.12.7：ADC1 TRGO2 触发选择；§25.12.9–10：EOS/EOC/AWD、R1W0 和保留位。

新增 `SingleShuntPwm`，不重定义原六步 `PwmBridge`。ADC 新增 TRGO2 单槽读取和离散看门狗接口。原 `clear_events` 仅将写值 0 修正为 0x04：手册 §25.12.10 的复位值为 0x0F，bit2 RFU 要求保持默认值；所有真实事件仍写 0 清除。新单槽 `take_single` 写 0x1c，保留 RFU 和 AWD，仅清 EOC/EOS。旧 API 的事件顺序、01–06 控制算法和源码不变。

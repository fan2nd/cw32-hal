## 存储与时间预算

当前 8 kHz 首样本预算修正版构建：text=20132 B、data=592 B、bss=1304 B，即约 20724 B Flash 和 1896 B 静态 RAM。CW32L012C8 链接区为 64 KiB Flash / 8 KiB RAM，剩余 RAM 还要容纳运行栈，未测栈高水位。

8 kHz 每帧为 12000 个 96 MHz CPU tick。调制最大比较值限制为 6000，最晚第二样本服务时刻为 5578，控制截止点为 11400，预留约 60.6 µs。早期 update 服务截止为 CNT=700。第一样本的读取容差仅 128 tick（约 1.33 µs），必须验证所有短临界区与 ISR 的实际最坏延迟。

纯控制/采样 ARM 汇编没有浮点或 64 位除法调用；速度诊断使用少量 64 位乘法，整个程序的启动时钟校验仍可能使用 64 位运算。除法调用点数量不是一次控制迭代的周期数。尚无 Cortex-M0+ 实测 WCET，运行时 deadline/漏采样检测只负责失败关断，不构成性能证明。

`max_control_ticks` / `max_update_ticks` 为运行时辅助观察，未覆盖完整异常入口/退出。实时采样期间没有日志调用；首故障关闭桥臂、停止 ATIM 触发并禁用高频 IRQ 后，I/O 线程才打印冻结快照。waker 的 clone/drop/wake 位于短临界区之外。

## 首样本超时与 8 kHz 整体调度修正

本次基线 `a2a4e908e8e4557a06c60fa8fc13e649dfad4e3a` 对应上版完整 313 文件源码包。新日志 `sample=1 entry=3608 read=3646 expected=3290..3418 previous_end=3533 max_first=764 frame=44050` 的重要证据是：前一个首样本 ISR 记录的结束计数已晚于第二样本截止。`max_first` 是历史最大值，不应直接认定它就是这次首样本耗时；旧版 site=0 的 state_before/armed_before 未填写，也不能用来证明故障前未解锁。校准在第 2048 个样本结束，frame=44050 不属于初次校准终结路径。ARM 审查发现已解锁首样本仍调用软件电流除法。

每个已解锁样本现在以原始值即时检查电流：原有向零截断的 `abs(numerator / 4095) > 750` 精确等价于 `abs(numerator) >= 751 * 4095`。电源轨和硬件看门狗仍逐样本检查，任何失败立即锁存停机。两个 mA 换算仅移到第二样本之后，仍先于 ADC2 更新 VDDA，因此二者沿用原采样时比例。首个 SampleInvalid 等非 Timing 故障也会保存关断前状态；若纯控制器已先进入 Fault，硬件层保存的是当时的 Fault，不宣称能追溯更早状态。

采用 8 kHz / 12000 tick，窗口由 576 增至 960 tick（6→10 µs），占空比范围 1200–6000，初始触发 [2880,3840]。死区 96、模拟建立 240、保持 140、转换 170、采样容差 128、reload 截止 700 均保持实际时间不变。控制截止为 11400，仍距下帧 600 tick；最晚第二样本读数 5578，给控制计算留出 5822 tick（约 60.6 µs）。降低每秒中断次数与增加真正的两次 EOS 间隔同时实施，没有单纯加大 ARR 或放宽迟到接收判定。

当前电流 PI Q15 为 9008/4311，PLL 为 5120/25。反电势滤波 alpha=10/64 近似保持原物理时间常数，群延迟补偿相应改为 54/10 帧；8 kHz 速度换算使用精确商 `magnitude*536 + magnitude*13608/15625`，无需 64 位除法。速度环仍 100 Hz（80 帧），ADC2 每 1 ms（8 帧）发起、3 ms（24 帧）超时，诊断每 50 ms（400 帧）。启动、自举、对齐、资格、失锁和失速时长均由 CONTROL_HZ 导出。电流指令斜率保留每帧 1 mA，物理斜率从 10 A/s 略降为 8 A/s；校准仍取 2048 个样本，约 128 ms。两帧命令延迟从 200 µs 增为 250 µs，需要实板验证。

没有直接采用 5 kHz：同一开关 RL/机械模型在 5 kHz、多个采样窗口和普通增益/滤波组合下不能连续满足原有反电势/PLL/角度资格而超时。独立诊断仅把观测器 R·I 中的端点梯形平均改成模型积分得到的真实平均，便恢复轻载闭环，说明更大开关纹波放大了该近似的误差。模型真实平均不可直接在硬件取得，此诊断没有伪装成固件修复；所有资格门槛和超时未放宽。最终选择通过同模型检查的 8 kHz / 10 µs 组合，而非仓促改造观测器。

最终验证：

- Rust 1.99.0，`thumbv6m-none-eabi` release、`-D warnings` 和全部 07 Rust 文件 rustfmt 检查通过。现有 proc-macro-error2 的未来兼容性提示仍由 Cargo 报告；不是本次新编译警告。
- 正常已解锁首样本的最终 ARM 外层路径 115 条 Thumb 指令、没有函数调用；基线为 131 条并调用一次 `__aeabi_idiv`。统计不含被调用除法函数体，不是硬件周期或 WCET 证明。
- 41 项独立外部回归覆盖控制、采样、调制、五路预载、启动/停止/故障流水线，以及真实源码抽取的 2048 样本校准、偏置/噪声拒绝、保持按键不能自动启动、Bootstrap→Align 和原始过流保护。采样扫描包含 129600 组电压/角度/母线组合及 200000 个随机边界输入。

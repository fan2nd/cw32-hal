### 修改及数学依据

- Flash：RM1.4 §§4.3.8、4.7.11、7.9、7.10.2 与官方 FLASH SDK 确认预取/缓存初始关闭、可带 KEY 配置。新增 L012 窄接口借用 FLASH 单例，不复位、不擦写、不碰保护；检查 busy/read mode/cacheinvalid，保留 RCC 的三等待周期，设置 FETCH/CACHE 并回读。AHBEN.FLASH 只控制配置接口；07 在任务/PWM 启动前调用并记录旧状态，随后 DSB/ISB。07 不执行 Flash 擦写、永久保留单例；01–06 不调用新接口。已有 Flash 擦写驱动的缓存关停/失效/恢复逻辑不变。
- EAU：内部 run 与有类型入口内联，HardwareMath 保留一个共享入口。对同一旧算法的隔离编译实验，旧 signed HAL 两层成功分支共 74 条执行 Thumb 指令（还不含外层 HardwareMath）；新共享完整入口为 37 条，无嵌套函数调用，每个额外 BUSY 轮询增加 6 条指令。这是指令路径比较，不是时钟或 WCET。寄存器顺序、64 次有限轮询、错误立即停 PWM 和错误优先级均保留。
- 采样：首降相在两个保持时刻间的 -2Vbus/3、-Vbus/3 两段使用指数 RL 运输；指数表由所配置 R/L 编译期生成。运行时仅 257 项 Q15 表及线性插值，无浮点、指数函数或运行时宽整数除法。
- 观察器：显式 RlInterval 包含真实 dt、a=exp(-R·dt/L)、指数加权电压响应 W；以 e=[W+R(a·i0−i1)]/(1−a) 逆解，替代失效的端点平均电阻压降。电压来自真实 staged/active PWM 边沿与对应母线，不使用植物内部电流真值或未限幅命令。反电势近似区间恒定，时间参考使用指数权重质心 L/R−T·a/(1−a)。

## 首样本超时与 8 kHz 整体调度修正

本次基线 `a2a4e908e8e4557a06c60fa8fc13e649dfad4e3a` 对应上版完整 313 文件源码包。新日志 `sample=1 entry=3608 read=3646 expected=3290..3418 previous_end=3533 max_first=764 frame=44050` 的重要证据是：前一个首样本 ISR 记录的结束计数已晚于第二样本截止。`max_first` 是历史最大值，不应直接认定它就是这次首样本耗时；旧版 site=0 的 state_before/armed_before 未填写，也不能用来证明故障前未解锁。校准在第 2048 个样本结束，frame=44050 不属于初次校准终结路径。ARM 审查发现已解锁首样本仍调用软件电流除法。

## 第二样本控制跨周期与 EAU 修正

本次发布基线为 `291918f30412eaba64f1d749899b0f568eac428e`。台架 `start=4097 observed=458 reload=true state_before=3 max_control=61897` 的 61897 来自错误的 u16 模 65536 差值；12000 tick 周期内至少一次回绕对应 8361 tick 下界。UIF 不能计数多次回绕，不能声称已经精确测到 8361 或 61897 个 CPU 周期。新诊断按 PWM 周期计算保守下界，处理 CNT/UIF 非同时读取的边界，并把迟到/回绕排除在成功帧的 max_control 之外。

## 250 mA 启动超时的电压余量与连续资格证据

本次基线为 `ffd417d822a57b891e1d86aa8d8ebdba7faea02d`。用户新台架：母线 7907 mV，强制 25 Hz，估计 24.641 Hz / 1140 mV；强制角差 -5350/65536 周（约 -29.39°），PLL 残差 -772；`reject=0 good=40/1000 best=125`。最后一帧合格不能代替连续 1000 帧，历史最长只有 31.25 ms；缺少历史拒绝位，不能断言此前只因角差门槛断串。

# 14 串口伺服

沿用 03 的 16 kHz 电流环和 2 kHz MT6701 采样。上电以当前位置为机械零点，释放后仍累计圈数，断电后重新计零。换相使用 01 保存在 FLASH 的电机标定。

## Cargo 入口

在本例程根目录执行 `cargo run --release` 会通过 SWD 烧录下位机。在 `host/` 执行 `cargo run` 会启动 Dioxus 桌面上位机；在 `host/desktop/` 执行同一命令也可启动。上位机使用本机编译目标。

## 启动

1. 从本目录执行 `cargo run --release`。电流零点、01 标定及 SSI 初始读数均通过后，设备开始监听串口，功率桥保持释放。
2. 用与板上逻辑电平匹配的 USB-UART 连接：**板 PB12/TX → 适配器 RX，板 PB11/RX ← 适配器 TX，两端 GND 相连**。UART1 使用 1,000,000 baud、8N1，无流控。收发分别使用 DMA 通道 2 和 1。
3. 用桌面 Edge 或 Chrome 打开 [上位机](host/index.html)，点击「连接串口」并选择适配器。连接会释放旧指令并读取设备参数。
4. 在「控制」选择模式并填写给定。「调参」设置限制与增益。点击「应用并使能」后整组参数生效；后续调整通过「应用更新」发送。「释放」立即请求关桥。

| 模式 | 给定 |
|---|---|
| 位置 | 多圈机械角，单位 °，分辨率 0.1°，范围 ±1000 圈。由 0° 给 +720° 代表正转两圈。 |
| 速度 | 双向 rpm，最大 ±600。给零速时制动；释放按钮关 MOE。 |
| 力矩 | 双向机械 Iq 计数，最大 ±200。 |
| MIT | 多圈位置 °、速度 rpm、Kp（Iq/°）、Kd（Iq/rpm）、前馈机械 Iq 同帧生效。 |

速度 PI 的输入值沿用 03 的分子表示（默认 Kp=125、Ki=6，分母分别为 64 和 256）。力矩及 MIT 模式在达到速度上限后抑制同向转矩，保留反向制动。所有参数仅在 RAM 生效。

前台 Embassy spin 执行器收发数据。主机每 50 ms 发心跳，外环检查最后有效心跳；250 ms 无心跳即释放，恢复心跳后需显式使能。页面进入后台、系统休眠或串口断开均可能触发超时。驱动故障先释放并排查原因；编码器连续超过 10 ms 无可信样本时需重新上电或复位建立多圈原点。

## 帧格式

整数均为小端。每次发送 64 字节，前 32 字节为命令，其余填零以支持分块重同步；等待一条 48 字节应答再发下一帧。

| 偏移 | 命令 | 应答 |
|---|---|---|
| 0–1 | ASCII SC | ASCII SR |
| 2、3 | 操作码、序号 | 状态（0 成功，1 拒绝）、回显序号 |
| 4 | 模式 1–4（顺序见上表） | 设备接受的模式 |
| 5–8 | i32 角度 ×10 | 回读 |
| 9–26 | 九个 i16：rpm、Iq、MIT Kp ×100、MIT Kd ×100、速度上限、Iq 上限、位置增益、速度 Kp、速度 Ki | 回读 |
| 27 | 保留 | bit0 已使能，bit1 MOE，bit2 故障，bit3 心跳超时 |
| 28–35 | 30–31 为前 30 字节 CRC | i32 实测角度 ×10、i16 rpm、i16 机械 Iq |
| 36–47 | 填零 | 36–39 为上电后 SysTick 超时次数（u32），40 为本次使能的首次关桥原因，41–45 保留，46–47 为前 46 字节 CRC |

关桥原因从新一次使能开始记录，释放后仍可读取。0 表示尚无记录，1 为 SysTick 超时，2 为编码器无效，3 为母线电压异常，4 为超速，5 为相电流保护，6 为心跳超时，7 为主动释放，8 为新连接释放旧指令。SysTick 每次退出时检测到下周期已挂起，超时计数增加一次。

CRC-16/CCITT-FALSE，初值 0xffff。操作码 1 为心跳/回读，2 为应用并使能，3 为释放及清故障，4 为建立会话并释放旧指令。只有心跳续租。CRC 损坏的帧无应答，参数越界返回拒绝且保留旧设置。MOE 关闭时电流环停止更新 Iq。

## 电流波形

打开上位机「电流」页即订阅，切回「控制」或「调参」即取消。三相电流、PWM 指令占空比、dq 电流三图共用时间轴，显示最近一秒。冻结后可选 1 s、200 ms、50 ms 并拖动窗口。指向任一图可读取该时刻的五路 ADC 电流计数、三路实际写入的 CCR 及其占 ARR 的百分比。Ic 由 −Ia−Ib 重建，Id/Iq 使用控制器电气坐标。关桥、故障和丢样区间都留空。冻结期间心跳和释放按钮继续工作。

原有 SC/SR 帧长度不变。SC 操作码 5/6 分别订阅/取消（不续心跳）；SR 状态字节 bit4 表示已订阅。订阅时 UART1 可在控制应答之间主动发送 138 字节的 SW 帧，所有多字节数均为小端：

| 偏移 | 内容 |
|---|---|
| 0–1 | ASCII SW |
| 2–5 | 本批第一个采样的 u32 序号，重新订阅从零起，按 2 kHz 递增 |
| 6–7 | 16 位有效掩码，bit0 对应第一组。无效组不能绘制为零电流 |
| 8–135 | 连续 16 组，每组依次为 Ia、Ib、Id、Iq 四个 i16 |
| 136–137 | 前 136 字节的 CRC-16/CCITT-FALSE |

接收按帧头、长度和 CRC 解码；序号跳变处断线，不插值。控制应答优先于下一批波形。设备在心跳失效或会话重建时取消订阅。

操作码 7 订阅同步电流与 PWM，与原有操作码 5 共用取消操作 6。扩展帧为 236 字节：0–1 为 ASCII SP，序号及有效掩码沿用 SW；8–9 为实际 ARR，10–233 为 16 组记录，每组依次为四个有符号电流计数和三个无符号 CCR 小端值，234–235 为 CRC。CCR 对应本次采样后写入的预装载值。计数器更新事件使其生效。

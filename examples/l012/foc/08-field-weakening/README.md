# 08 无感弱磁

静止启动时，初次扫描期间给定达到 96 rpm 即进入开环拖动，同时运行 HFI。定位 0.5 s、升速 2 s 后，连续 48 ms 满足载波、速度与磁轴角度条件才接管，再用 32 ms 撤完开环电压。接管时按开环电压初始化电流 PI，以实测基波电流为初值，在 128 ms 内过渡到闭环电流指令；前 1.2 s 速度给定最高为 96 rpm。低给定保留原静止扫轴流程。fault=14 表示拖动期间未在 4 s 内取得一致的速度和磁极。

在本目录运行 `cargo run --release --locked`。电位器归零至少 100 ms，再逐渐提高给定至 600 rpm。低速沿用 [07 的 HFI 与 EMF 切换](../07-hybrid/README.md)。MT6701 仅供故障对照。

BTIM1 每毫秒滤波一次三相占空比的最大差值。EMF 已接管、给定至少 360 rpm 且反馈至少 340 rpm 时，差值超过满量程的 78% 会每毫秒增加一个计数的负 Id，低于 73% 则逐步撤去。Id 最低 −80 ADC 计数（本板约 −0.20 A），Iq 的正负给定同时受电流圆约束，Id² + Iq² ≤ 200²。回到 HFI 时电流环立即使用 Id=0。

RTT 的 `live` 通道显示角度来源、目标、反馈和 Id/Iq 给定（ADC 计数）。固定负载逐渐升速，观察进入 emf 后 idref 是否转负，降速后是否回零。保留 600 rpm 给定上限；如果电压余量充足，即使满给定也会维持零 Id。

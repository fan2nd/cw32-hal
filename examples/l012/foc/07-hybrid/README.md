# 07 HFI 启动与反电动势高速换相

在本目录运行 `cargo run --release --locked --offline`。电位器归零至少 100 ms，抬起后按 06 的流程定位、复扫并进入速度闭环。给定范围为 0–600 rpm，速度环由 BTIM1 以 1 kHz 执行，电流环为 16 kHz。MT6701 仅用于故障位移对照。

| RTT | 角度来源和动作 |
| --- | --- |
| `hfi` | 高频注入换相。同时估算反电动势。目标和 HFI 速度均达到 360 rpm 后，两者连续 32 ms 转速相差小于 40 rpm、电角度相差小于 15° 且信号有效，才允许接管。 |
| `emf` | 关闭注入，反电动势观测器提供角度和速度，电流 PI 使用 ADC 相电流。切换时补偿两估算角之间的差，并逐拍撤去补偿。 |
| `relock` | 估速低于 280 rpm，或给定低于 320 rpm 且估速低于 360 rpm 时恢复注入，用当前反电动势角度和角速度初始化 HFI。连续 6 ms 角差小于 25°、速差小于 65 rpm 且两路信号有效后回到 HFI。 |

观测器用 SVPWM 限幅后的三相占空比和母线实测电压重构定子电压。升至 200 rpm 后，ADC 每拍累计电压和相电流，每 16 拍交付一次采样窗口。BTIM1 在较低中断优先级计算 αβ 平面的反电动势，ADC 按窗口时间戳外推当前电角度，扣除电阻压降和电感项。换算以本板 2.442 mA/ADC 计数、JD4631 相电阻 6.7 Ω、相电感 1.75 mH 为依据。当前相序下，正机械转速对应负电角速度。算法依此将反电动势矢量旋转 90° 得到转子轴，并补偿采样窗口的半周期延迟。

`fault=12` 表示反电动势控制期间连续 8 ms 信号不可靠，或低于 100 rpm 时 HFI 未能及时重新锁定。故障会关桥，电位器归零后复位。其余故障码见 [06 说明](../06-sensorless/README.md)。

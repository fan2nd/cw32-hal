# 五段式 SVPWM 速度闭环

先运行 01 保存标定。在本目录执行 `cargo run --release --locked`，将电位器归零再抬高。电位器对应 0–800 rpm，速度环为 2 kHz，ADC1 电流环为 16 kHz，可与 03 在相同给定下对照。

05 使用低侧钳位：电流环算出三相比较值后，从三相同时减去最小值。这样保留线间占空比差，最低占空比相的上管在本周期内保持关闭。中心对齐计数下，从计数峰值开始，若 A、B、C 占空比依次递减，一个完整周期的上管状态为 `000 → 100 → 110 → 100 → 000`。扇区变化时交换相序，边界处零时长段会合并。

示波器可同时观察 PB5、PB6、PB7（三个上管 PWM）。稳定旋转时，钳位相随机械转动对应的电角度轮换；零电压指令对应三相比较值全零。停机仍会关闭总输出 MOE。

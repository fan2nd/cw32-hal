# 12 机械 1 rpm 开环

先运行 01 完成标定。在本目录运行 `cargo run --release --locked`。上电后用 500 ms 将指令坐标系的 Id 升至 200 个 ADC 计数，先关闭软件死区补偿，按机械 +1 rpm 和 −1 rpm 各走 60 秒；再开启补偿，重复相同正反转。运行中 Id 固定为 200，Iq 为零。每次 ADC1 完成两相扫描，电流 PI 更新 SVPWM 电压。四圈结束自动关桥，复位可重测。

四圈的硬件死区设置均为 2 µs。软件补偿在三相 PWM 比较值上按相电流符号增加或减少计数，C 相电流从 −Ia−Ib 得到。中心对齐计数时，每周期的导通时间变化等于比较值修正量的两倍，因此比较值最大修正量取半个死区的定时器计数。相电流在 ±16 个 ADC 计数以内按比例减小修正量。

每 1 ms 根据标定的方向、极对数和指令速度推进电角度。MT6701 仅做对照，每 10 ms 采集一次绝对机械角；每 20 个样本合并发送一条 RTT，end_ms 是最后一个样本的时间，65535 表示读取失败。机械角采用板级正方向，一圈为 16384 计数。母线允许 8–16 V，三相任一相电流偏移达到 2000 ADC 计数时关桥锁停。

将完整 RTT 保存为日志，运行 `python3 analyze_orders.py /path/to/run.log`。脚本从相邻样本差分得到 10 ms 平均速度，按实际机械角中点对齐，以运动方向为速度正向，分别对各圈联合拟合 66 阶和 264 阶正余弦。2048 个机械角分箱中每个有数据的分箱总权重相同。输出是转速波动峰值（rpm）及相位，相位定义为余弦峰的位置乘以阶次。

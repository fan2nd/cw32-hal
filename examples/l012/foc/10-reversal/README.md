# 10 编码器闭环快速往返

在本目录运行 `cargo run --release --locked`。空载上电，ADC 零偏和 01 FLASH 标定有效后，电机自动从静止加速，持续在 +600 和 −600 rpm 两个速度端点间往返。电位器不参与。

16 kHz 电流环使用 01 标定换算电角度。2 kHz 外环读取 MT6701，通过约 2 ms 的速度滤波判断是否越过目标。首次到速时开始计时，速度 PI 闭环维持该方向的 600 rpm。满 1 秒 的同一拍把机械转矩电流给定切到反方向的 200 计数（约 0.49 A），制动、过零和反向加速期间保持开桥。换向不设指令斜坡。给定限幅、相电流保护、8–16 V 母线监测、±660 rpm 超速、编码器检查和 5 s 到速超时（单独计时）均生效。故障关桥锁停，复位后再运行。

RTT 每个端点报告编码器反馈、反向给定到达速度端点的耗时、切换至过零耗时、该程采样母线最高值和实测平均电角 Iq。恒速结束另报方向、实际保持时长和该段平均转速。第一程从静止开始，过零时间为 0。速度阈值按未取整的滤波反馈判断，会有少量越过 600 rpm 的读数。

此前不设恒速段的空载对照中，电流 PI 积分系数沿用 03 的 64 时，首次起转耗时 4.32 s，反向 5 s 超时时反馈为 −234 rpm。10 单独改为 32768，相同 200 计数限幅下，一组限次验证的首次起转为 38 ms，随后 10 次完整换向为 58.5–61.5 ms，过零为 27.5–30.0 ms。另一次连续运行中也出现约 85 ms 的换向。计时基于编码器滤波反馈，数值随负载、供电和工况变化。

此前使用 2 s 恒速设置时，空载限次测试连续四段各保持 2.000 s，正、反向编码器平均转速分别为 +599 和 −599 rpm。三次换向用时 80.5、77.0、80.5 ms。

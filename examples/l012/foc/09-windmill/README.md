# 09 顺风接管与逆风制动

静止启动时，初次扫描期间给定达到 96 rpm 即进入开环拖动，同时运行 HFI。定位 0.5 s、升速 2 s 后，连续 48 ms 满足载波、速度与磁轴角度条件才接管，再用 32 ms 撤完开环电压。接管时按开环电压初始化电流 PI，以实测基波电流为初值，在 128 ms 内过渡到闭环电流指令；前 1.2 s 速度给定最高为 96 rpm。低给定保留原静止扫轴流程。fault=14 表示拖动期间未在 4 s 内取得一致的速度和磁极。09 先做顺逆风探测，只有确认接近静止才进入上述流程。

在本目录运行 `cargo run --release --locked`。先归零至少 100 ms，让外力带动电机，然后抬起电位器。正方向沿用 03。给定范围为 0–600 rpm。电位器归零立即关桥，可重新尝试。

开桥后先在静止 αβ 坐标系将两轴电流给定置零。使用实际 PWM 占空比、母线电压和两相电流，每毫秒重构一次反电动势，跟踪其旋转方向。该阶段需要开桥采样，MT6701 只用于故障对照。

| 测试条件 | 动作和可观察结果 |
| --- | --- |
| 顺风 | 连续 32 ms 观测有效且至少 +120 rpm，将电流 PI 的电压积分旋转到转子坐标系，直接交给 EMF 速度闭环。随后可按 07 的规则回到 HFI。 |
| 逆风 | 连续 24 ms 有效且不高于 −40 rpm，按反向转动的磁极角产生正机械转矩制动，给定最大 60 ADC 计数（约 0.15 A）。失锁或接近零速时撤去制动。 |
| 静止或逆风已减速 | 反电动势幅值连续 100 ms 低于 180 mV，转入 HFI 静止辨轴、对齐和启动。此门槛代表信号接近静止，不能分辨极慢的转动。 |
| 外力持续或方向不明确 | 捕获阶段最多 3 秒；超时关桥，报告 fault=13。回零后可重试。 |

RTT 的 live 通道显示 capture/hfi/emf/relock、目标和反馈。wind=1 表示顺风接管，−1 表示本次启动执行过逆风制动，0 表示尚未识别到带速动作。比较两种方向时使用相近的起始转速，逆风测试的母线电源需能承受回馈。母线有效范围为 8–16 V。其余运行与故障码见 [07](../07-hybrid/README.md)。

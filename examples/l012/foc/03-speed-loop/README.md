# 速度闭环

电位器控制 0–600 rpm 的速度给定。SysTick 每 500 µs 直接读取 SSI、执行速度 PI 并发布 Iq。更高优先级的 ADC1 中断以 16 kHz 执行电流环。主循环负责 LED、RTT 和其他应用任务。固定 HSI 时钟配置通过 HAL 的 `init_hsi` 初始化。运行前先完成[前两个工程的调试](../README.md)。

```sh
cargo run --release --locked --offline
```

板测现象、修正和复测结果见[速度环踩坑记录](踩坑.md)。

电位器读数 ≤150 时给定归零，151–200 保持上次给定，超过 200 后按原曲线升速，达到 3523 时给定为 600 rpm。

运行时每 500 µs 更新速度给定。归零会锁存停车请求，直到停稳关桥并再次采到零位。随后非零给定连续 20 ms 才重新开桥。转速高于给定时，速度 PI 请求反向转矩；运行中给定归零时主动制动。速度 PI 按百分比误差（目标减反馈，除以目标绝对值与 48 rpm 中的较小值，再乘以 100%）计算 Iq。速度 PI 的积分和输出均限幅至 ±200 个 ADC 计数。目标归零时，仅在当拍编码器位移和滤波速度均为正时制动，取两者对应速度的较小值，5 rpm 起给 200 个计数的制动电流，低于 5 rpm 按速度比例收小。速度绝对值连续 20 ms 不超过 1 rpm，且编码器位置保持在窗口起点 ±2 个计数内，才关桥。A/B 任一相滤波电流的绝对值超过 2000 个计数，或母线电压越界时关桥。

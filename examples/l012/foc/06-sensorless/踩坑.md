# 06 高频注入无感启动踩坑记录

本次板测使用 JD4631（11 对极），电流环 16 kHz，注入和 BTIM1 速度环均为 1 kHz。遇到“光响不转”或“动一下就停”，先看首次关桥的 `state`、`fault` 和 `iqref`。定位本身会牵动转子，进入 `state=3` 才开始输出速度环要求的转矩。

## 光响不转，Iq 一直为零

早期在几乎相同的转子位置，两档脉冲得出过相反的磁极极性。12 轴双向扫描可以拟合磁轴，但二倍角响应有 180° 电角度歧义。现在先沿候选轴的正交方向施加定位场，再撤场复扫，选择靠近定位场的一端。曾测得复扫偏差约 40.8°，超过 35° 时会触发 `fault=6`，此时应看定位、撤场回弹与复扫结果。

另一版连续 7 次触发 `fault=11`。其中一次给定已达 380 rpm，约 400 ms 内编码器原始读数保持在 15308，100 ms 间隔的估算角快照只相差约 1.4° 电角度，Iq 却始终为零。旧判据要求连续 32 次校正每次都小于约 0.18°，载波测量的抖动会反复清空计数。现在用连续 32 个有效载波周期内的角度峰峰值判稳，允许 5° 电角度摆幅，并要求磁轴仍在定位场 ±35° 内。静止捕获期间只校正角度，捕获完成后才开始累计速度。

## 已经动了一下，随即关桥

下面是降低锁相环速度积分增益**之前**的同一次启动。关桥记录锁存首次故障，保留了当时的给定。

```text
stop fault=8 state=3 target=191 rpm=-21 iqref=108
before stop: encoder_avg_rpm=2 hfi_end_rpm=-20 dt_us=8157
```

在关桥前约 8.16 ms，编码器位移折算的机械平均速度为 +2 rpm，窗口末尾的 HFI 估速已到 −20 rpm，随后到 −21 rpm，触发反转保护。另三次给定分别为 131、446、75 rpm，编码器窗口平均只有 0–1 rpm，HFI 窗口末值却为 −18 至 −20 rpm。这些数据表明转子在窗口内几乎没有净位移。窗口平均值和关桥瞬时值并非同一测量，无法由此排除短暂回摆。

降低起步转矩冲击也试过。速度环接入后的前 100 ms，Iq 限额每毫秒放宽 2 个 ADC 计数，最终到 ±200。改后在 Iq 给定仅为 46、88、92 时仍复现过同一故障。最后单独将 HFI 锁相环的速度积分增益降到原来的四分之一，保留角度校正增益与 −20 rpm 反转门槛，减少接入转矩时短暂相位误差对估速的影响。

改后板上连续启动两次。第一次给定 230 rpm，稳定后 HFI 反馈 226–231 rpm；归零再启动，第二次给定约 315 rpm，起步曾报 −11 rpm，稳定后约 311–316 rpm。两次均未触发反转保护。这两个工况验证了可起转，低速、不同初始角度和带载时的重复启动成功率仍待测。

## 容易混在一起的其他现象

| 现象 | 板测观察与处理 |
| --- | --- |
| 3–4 rpm 给定时不走 | 一次记录里编码器约一秒停在 7484 附近，Iq 给定多为 4–7。原速度 PI 采用绝对误差，给定从 4 跳回 3 又会清积分。现用相对误差和 1 rpm 给定滞回，3 rpm 持续运行仍待验证。 |
| 无感和有感的正转方向相反 | 03 使用处理后的机械角，本板标定方向为 −1；早期 06 以电角度递增为正。06 现在用同一个方向系数换算速度反馈和 Iq 指令，HFI 仍在电角度坐标系中工作。定位时的短暂摆动不能判断持续转向。 |
| 电流 PI 跑在 16 kHz，反馈却慢一拍 | 早期只在每个载波周期更新一次基波电流，16 次 PI 更新重复使用同一反馈。现在每次 ADC 采样都与前半个载波周期（8 个样本前）的相电流取均值，抑制交变注入分量。 |
| 转起来却看到 `target=0`，加实时打印后又出现 `fault=10` | 旧版在停机后回放历史，当前给定此时已清零。后来在运行中打印长 defmt 帧，板测出现 ADC 超时。现在主循环通过独占的 RTT 通道每 500 ms 打印一次目标与估速，ADC 可抢占。首次故障数据单独锁存，`fault=8` 时再打印关桥前的编码器对照。 |

复测时让电位器归零至少 100 ms，再抬到要测的给定。从不同静止位置重复，分别记录是否通过静止捕获、是否进入速度环，以及是否能持续转动。运行日志里的 `rpm` 来自 HFI；MT6701 只读角度用于诊断，未参与换相、速度反馈或反转保护。

# 高频注入无感速度闭环

板测中遇到的静止捕获超时、起步误报反转及对应 RTT 记录见[踩坑记录](踩坑.md)。

默认 `Mode::Drag`，上电自动测试开环拖动转 HFI 闭环。16 kHz 电流中断同时输出开环旋转电压与 1 kHz HFI 方波。先定位 0.5 s，再用 2 s 升至约 96 rpm。开环场与最近磁轴端的夹角小于 45°、HFI 估速在 78–114 rpm、载波有效且选极连续一致 48 ms 后进入 state=3。用 32 ms 将基波电压从开环矢量过渡至 HFI 角度下的电流 PI 输出，随后完全撤掉开环场。HFI 注入方向保持连续。捕获超时报告 fault=13。

自动测试闭环给定先保持 96 rpm，再升到 160 rpm，两秒后关桥回放日志。MT6701 仅用于记录，无需手动调电位器。常规电位器模式在启动目标至少 96 rpm 时使用此接管，较低目标保留原静止 HFI 启动，避免为低速指令主动拖至 96 rpm。

选择 `Mode::StaticScan` 可运行此前的静止对照诊断。先用 01 完成 FLASH 标定；06 只读方向、极对数和零位，用于把 MT6701 读数换算为电角度。上电自动运行一组，电位器不参与，空载运行约 36 秒。定子场依次命令 12 个位置，每步 30° 电角度，定位 500 ms，撤去定位场 300 ms，每个位置独立扫描 3 次。完成或故障后关桥锁停，复位才开始下一组。关桥后回放逐轮结果。

每轮 HFI 直接输出扫描估角，不按定位场选择极性。主循环约每 2 ms 读取原始机械角，对跨零读数展开后取均值，按 01 的方向转换为参考角。扫描中参考角峰峰值超过 5° 电角度、读数失败或采样覆盖不足时，该轮记为参考无效。磁轴对比度低于 6 个 ADC 计数时记为弱轴。参考无效轮次排除；弱轴轮次不计入 HFI 角度统计，但保留固定轴脉冲数据。

`axis_deg_x10` 是估角减参考角后按 180° 折叠的磁轴误差，单位 0.1° 电角度。正负脉冲差为零或整角误差恰为 ±90° 时极性未定；其余轮次按整角误差是否超过 90° 记错。每个位置打印有效轴样本数、平均绝对误差、最大绝对误差、判错数和可判次数；`summary pos=0` 为 36 轮总计。`ref_q16` 用于核实各位置实际间距。

每轮先按原流程辨轴，再沿预先指定的定子轴交错探测。探测轴为定位场电角度对 180° 取模，因此第 1–6 个位置与第 7–12 个位置分别共用六条定子轴，实际转子角由编码器事后核实。每条轴测 0、900、1800、2700、3600、5400 Q15；0 档使用相同的采样时序作为零输入对照。每档正负脉冲各 8 次，交替先后顺序。每次扣除本次基线，记录第 2、4、8 个 ADC 周期的响应。关桥后 `matrix` 行的 p、n 均为 8 次响应之和。已有 `summary` 仍统计前置 12 轴扫描，不统计固定轴脉冲。

将 `MODE` 设为 `Mode::Speed` 可恢复原无感速度闭环。该路径无需 01 标定；MT6701 只记录故障前位移。机械转速换算使用 JD4631 参数中的 11 对极，更换电机时需匹配极对数。机械正方向与本板 03 一致。01 测得方向为 −1，因此在速度反馈与 Iq 指令处使用同一个方向系数。HFI 在电角度坐标系中运行。

在本目录运行 `cargo run --release --locked --offline`。在常规速度闭环模式下，空载静止时将电位器归零至少 100 ms，再从小给定开始。电位器对应 0–600 rpm，600 rpm 为给定上限。归零会撤去 PWM 输出，下次启动重新扫描。

| RTT 状态 | 控制动作 |
| --- | --- |
| 0 | 关桥，等待有效给定或故障复位 |
| 1 | 预装载中性占空比 |
| 2 | 在半个电周期内扫描 12 条轴，每条轴正负脉冲各重复 8 次，交替脉冲次序。用全部 12 个双向响应拟合二倍角谐波，取相位的一半作为候选磁轴，再进入定子磁场定位。扫描约 480 ms |
| 4 | 在候选轴的正交方向施加固定定子磁场，100 ms 渐升到 25% 电压，保持 400 ms，撤场 300 ms。此步会牵引转子，初始运动方向取决于静止位置 |
| 7 | 再扫描约 480 ms，在两个候选磁极中选取靠近定位场的一端。偏差超过 35° 电角度时关桥 |
| 8 | 仅输出 HFI 载波，至少观察 100 ms。静止捕获只校正角度。连续 32 个有效载波周期内估算角的峰峰值不超过 5° 电角度，且估算轴与定位场偏差在 ±35° 内，才启用速度积分与速度环 |
| 3 | 连续叠加 1 kHz 方波（每半周期 8 个 ADC 样本），将正峰与前后两个负峰的均值做差，用解调出的 q 轴响应驱动锁相环，抵消采样窗口内线性变化的基波电流，使用估算角度换相。锁相环误差归一化使用 EAU 有符号除法，硬件不可用时回退到软件除法。16 kHz 电流环每次取当前样本与前半个载波周期样本的均值，BTIM1 更新中断中的 1 kHz 速度环使用估算转速，按相对速度误差给转矩，给定保留 1 rpm 滞回，接入后的前 100 ms 每毫秒放宽 2 个 ADC 计数的 Iq 限额，直到 ±200。估速高出目标不足 160 rpm 时，反向制动电流上限随超出量线性收小，到目标时为零 |

本版按 d 轴为小电感轴设计。可在多个静止位置重复启动，观察极性复核结果和原始机械角的变化。`est_q16` 表示无感估算电角度。连续注入依赖该电机在实际转速、负载下的凸极响应，全速范围需要用对照数据验证。

`axis_contrast` 是拟合二倍角谐波的峰谷差，`polarity` 是最佳轴上的正负脉冲响应差，单位均为 ADC 计数。`align_field_q16` 为定位场电角度，`align_error_q16` 为复扫角度减去定位场角度的有符号差，一圈为 65536。`stop` 行保留首次关桥时的状态、目标、估速与 Iq 给定，`overrun_cycles` 保留最近一次 EOS 重叠时从中断入口到检测点的核心周期数。故障时关桥，保留两项读数供诊断，电位器归零后复位。

| fault | 原因 |
| --- | --- |
| 1 / 10 | ADC 更新频率异常 / 单次处理跨过下一次转换 |
| 2 / 3 / 4 | ADC 结果缺失 / 母线越界 / 任一采样相电流绝对值超过 2000 计数 |
| 5 / 6 | 轴向对比度小于 6 / 复扫磁轴与定位场偏差超过 35° |
| 7 | 连续 16 个载波周期的响应不足或相位误差过大 |
| 11 | 500 ms 内未取得稳定磁轴 |
| 8 / 9 | 估算转速越界 / 启动或运行中持续两秒达不到运动门槛 |

速度闭环时，主循环每 500 ms 在 RTT 通道 1（`live`）打印 `target` 和 `rpm`，单位均为机械 rpm。此通道由主循环独占，ADC 中断可抢占打印。通道 0 保留启动和故障诊断。

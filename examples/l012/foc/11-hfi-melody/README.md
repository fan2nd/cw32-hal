# 11 高频注入旋律

在本目录运行 `cargo run --release --locked`。使用 L012 FOC 板原有的三相桥、电机和电流采样接线。上电或复位后，固件关桥采样零点，随后自动播放《东方红》开头八小节，两遍共约 20 秒，最后关闭功率桥。播放无需电位器、编码器或 01 标定。固定轴交变磁场可能使转子轻微振动。

ATIM 以 16 kHz 运行。每次 ADC1 完成两相扫描，固件在固定定子 α 轴输出一个双极性方波电压采样点，β 轴给定为零，通过七段 SVPWM 驱动绕组。音高为 392–587 Hz。每个音符的起落沿各约 4 ms，末尾留出 30 ms 关桥间隔；音量取决于电机和安装方式。

在 [main.rs](src/main.rs) 的 `SCORE` 中编辑频率（Hz）和时值（每单位为一个八分音符，312.5 ms）。注入峰值为 2700 Q15，母线电压窗口为 8–16 V。ADC 超时或三相中的任一相电流偏离零点超过 128 计数时关桥，故障后须复位。RTT 在播放完成后报告音符数、各音符实测时长、A 相峰峰值和三相峰值电流计数。

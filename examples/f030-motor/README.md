# CW32F030 电机控制示例

`tb6612/` 是面向 CW32F030C8T7 的独立 Cargo 工程，两个固件共用同一套运动控制和 UART 报告代码。

## TB6612 丝杆定距运动

`tb6612_distance` 和 `tb6612_external_gate` 均在上电后循环向前推进：
每段从当前位置起算 10 mm，到位后停车 2 秒、打印误差，再启动下一段。
电机侧 A/B 编码器每相每转 7 个周期，四倍频、50:1 减速、单线 M3×0.5
对应每丝杆转 1400 计数，每段目标为 28000 计数。请先确认电机转一圈实测
28 计数。以下为 ATIM 刹车方案接线。

| F030C8T7 | 接线 |
| --- | --- |
| PA0 / PA1 | 电机编码器 A / B，正向时 GTIM2 应递增 |
| PA2 → PA6 | 必须短接：GTIM2_CH3 比较输出 → ATIM_BK（高有效） |
| PA5 | ATIM_CH1A → TB6612 PWMA |
| PB0 / PB1 | TB6612 AIN1 / AIN2 |
| PB2 | TB6612 STBY |
| AO1 / AO2（驱动板） | 电机两端 |

VM 接电机电源，VCC 接 MCU 兼容的逻辑电源，各模块共地；开漏编码器需要外部上拉。
上电自检在 STBY 低时让 PA2 输出高、低，验证 ATIM 刹车触发及解除后才允许驱动。
GTIM2 在编码器计数匹配 CCR3 时将 CH3 置高并保持。ATIM 设置 BKSA=2，
将 PWMA 强制拉低；STBY 此时仍为高，TB6612 进入短刹车。电机惯性和
机械回差会影响最终位移。可断开电机电源，用正交信号模拟多个行程，检查目标计数处 PA2 变高、PA5 停止输出 PWM。

两种固件都通过 UART1 TX（PA8）打印。接 USB 串口适配器的 RX 和共地，
设为 115200、8N1。停车的前 100 ms 为短刹车，随后进入待机；
满 2 秒时读取该段净位移并输出一行。串口发送和下一轮门控自检会增加少量段间时间。
下例是多走 2 个计数时的输出格式：

```text
cycle=1 target_um=10000 counts=28002 measured_nm=10000714 error_nm=+714 status=1
```

误差为本段编码器换算位移减去目标位移，正值表示过冲。纳米是打印单位；
滑台实际误差还受回差、导程和负载影响。程序每毫秒累加有符号计数增量，
可跨越 16 位计数器回绕。最后 20 µm 的占空比降至 25%，其余行程为 55%。
状态 1 表示正常完成；2 表示刹车链路异常；3 表示 180 秒行程超时；
4 表示 500 ms 无进展或明显反走。运动中发生故障时打印该段结果后停止循环；
上电或重新启动前的刹车自检失败时，仅打印故障原因。单向循环不含回程和行程限位，
请按实际可用行程安排停机。

从 `examples/f030-motor/tb6612/` 构建：

```sh
cargo build --release --locked --bin tb6612_distance
```

## TB6612 外部与门定距运动

`tb6612_external_gate` 使用相同的电机、丝杆、方向和 STBY 接线，PWMA 改经一个
与 MCU 和 TB6612 逻辑电平兼容的二输入与门。拆除上一方案的 PA2→PA6 跳线，
也要断开 PA5 到 PWMA 的直连。按下表接线，避免两个推挽输出相连。

| 引脚或节点 | 接线 |
| --- | --- |
| PA5（20 kHz PWM） | 与门输入 A |
| PA2（GTIM2_CH3，驱动许可） | 与门输入 B |
| 与门输出 Y | 同时接 TB6612 PWMA 和 PA6（GPIO 回读） |
| PA0 / PA1 | 电机侧编码器 A / B |
| PB0 / PB1 / PB2 | TB6612 AIN1 / AIN2 / STBY |

复位后程序保持桥待机，逐一检查与门四种静态输入组合，再检查比较通道已放行。
每段正向目标为 28000 个计数（10 mm）。GTIM2 计数匹配时，CH3 置低并保持，
所以即使 PA5 仍有 PWM 或编码器回退，PWMA 也保持低，驱动进入短刹车。
软件轮询负责减速、故障停机及结束后的待机。调试符号沿用上例，
`MOVE_STATUS=2` 在本方案表示门控自检或到位比较检查异常。
可断开 VM，保留逻辑供电并模拟 AB 输入，用示波器观察 PA2 和 Y 在目标处的变化。
制动后的电机侧计数可从 `FINAL_COUNTS` 读取，滑台实际停位仍需独立测量。

```sh
cd examples/f030-motor/tb6612   # 从仓库根目录进入
cargo build --release --locked --bin tb6612_external_gate
```

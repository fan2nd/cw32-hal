# 07：单电阻无感 FOC（独立实验例程）

当前 2.5 kHz 版本的模块架构、状态机、采样与预载时序、实测耗时及频率约束，见[详细架构与控制频率报告](../../../docs/debug-foc/2026-10-07-07-architecture-control-frequency.md)。报告包含最新启动超时结果，旧版闭环成功记录不代表当前版本已经调通。

面向 CW32L012C8 电机板，实际 R0 为 **10 mΩ**，覆盖原理图的 2 mΩ 标注。01–06 仍是独立的六步例程，07 不导入它们的业务源码。

本例包含电流重建、Clarke/Park、Id/Iq PI、双可测窗口调制、反电势模型和 PLL，以及有资格门槛的 OpenLoop → Blend → ClosedLoop。**当前台架已完成多轮无感接管并运行至约25电气Hz；不是通用电机即插即用固件。** 用户测得任意两根引线间 R=6.7 Ω、静态 L=1.75 mH，暂用平衡等效星形相模型 3.35 Ω/875 µH；这不证明动态 Ld/Lq、极对数、磁链或额定值。不能保证空载/带载启动成功，更不支持零速有载无感闭环。

## 当前台架固件（2026-10-07，提前接管修正版）

**上电、复位均为0档停机，无自动启动或定时停止。** 与06一样，六档包含停机档：PA3每次有效按下依次切换 **停机 → 30 → 60 → 90 → 120 → 150 → 停机**（电气Hz）。必须先释放60 ms再按住60 ms；长按不连跳，上电已按住也不启动。非零换档保留当前控制状态，通过10 Hz/s速度参考斜坡调速；故障仍锁存到复位。各档是目标频率，150 Hz为探索上限，尚未实机验证；此前稳定运行记录约25 Hz，实际可达速度仍受供电、电压限幅、电流与观测器稳定性约束。

当前3S／9.9 V欠压，实测约11.9 V；16 V过压、1.8 A软件跳闸、300 mA对齐、500 mA启动/接管电流圆；闭环运行Iq上限1.1 A。采样为2.5 kHz，首／第二触发延时5／2.5 µs，R=3.35 Ω、L=875 µH。

启动依次为5 ms自举、200 ms对齐、2→18 Hz强拖加速。在加速过程中，只要强制及估计速度达到12 Hz、反电势达到500 mV，并满足原方向／速度差／角差／PLL质量检查连续50帧（20 ms），即可接管。无需等待2.5 s平台；5 s开环总超时仍在。8–10 Hz接管曾失锁，因此保留本台架验证的12 Hz下限；这些参数不是所有电机的理论门槛。

接管帧保持原αβ电压，并转换PI和电流参考坐标。0.5 s Blend淡出Id、保持Iq；当前台架Iq下限为100 mA，通过3 mA/帧斜坡及500 mA电流圆逐渐达到。约48 mA过渡曾失锁，而稳定运行命令约70–76 mA。速度PI在Blend结束才初始化并启用，避免过渡中提前将转矩降至零。

反电势低通alpha=13/64，PLL为16384/256；速度反馈在2.5 kHz下用Q8、alpha=1/40低通，再供100 Hz速度环使用。速度PI Q15增益123/1，最高目标150电气Hz（探索设置）；原始PLL速度仍直接用于超速／失速保护；超速阈值165 Hz，PLL限幅180 Hz。命令电流和估计速度均不代替独立物理测量。

参数表：MYH-4621F，24N22P（11对极），KV=68 RPM/V，10–24 V；DC12 V/1.1 A为表列控制器测试工况，电流未注明母线或相电流口径。当前1.1 A是FOC指令配置，不是已确认的额定相电流。12 V空载估算816 rpm；30/60/90/120/150电气Hz对应约164/327/491/655/818 rpm。板级仍使用12 V台架及16 V过压门限，不因电机支持24 V而提高板级供电。

电压额度10240/32768=0.3125 Vbus，12 V时约3.75 V；原6500约2.38 V。PWM从4 kHz降至2.5 kHz，DUTY_MIN/MAX改为10%/65%，以保留控制计算时隙，尚不能使用完整母线电压。最高档是目标，不是已验证实转速度。

## 当前诊断

- `RUN_RESULT fault=0 state_before=6 state_age=...` 是此前有界台架固件的记录，表示正常台架结束前处于ClosedLoop，旧4 kHz日志state_age/4000为该状态持续秒数，当前2.5 kHz应除以2500。fault非零仍为原保护关断。开环资格不等同独立角度精度证明。
- `RUN_HISTORY`／`RUN_ROW` 保存最后最多32个50 ms闭环快照，字段依次为原始估计速度、电势幅值、Iq指令及滤后速度。只在停桥后输出。
- `REPLAY_BEGIN version=5 phase=Blend` 保存接管后age=1..80的连续输入，种子为Blend age=0；此时forced字段为停止推进的旧开环角，不能把后续observed-forced解释为转子负载角。初末状态用于检查观察器递推，不是独立转子角度。
- `HANDOFF_HISTORY eligible_frames` 统计强制速度达到12 Hz后的开环帧，包含加速段。最终固件在Blend／ClosedLoop停止时将HANDOFF reject置零，因为旧强制角已冻结，不能再作为接管判据。
- 记录、对照参数、已验证范围和原始日志见[提前接管调试记录](../../../docs/debug-foc/2026-10-07-early-handoff.md)。MODEL_TAG仅覆盖arithmetic/config/control/sampling原始字节，不覆盖io/hardware/trace；本次固件SHA256另见记录。

下文保留早期设计和排故背景；涉及4 kHz、旧定时tick、旧250 ms资格、平台等待及旧PI/滤波增益的内容属于历史，当前行为以上述参数和源码为准。

## 默认行为与保护

- 普通 release 构建包含功率输出和有资格无感接管，无额外功能门。上电六个输出保持低；首次 ADC2/BGR/VDDA 合格后才累计零点样本，当前固件只接受PA3手动选档启动，详见上节。
- PA3 连续释放 60 ms 后再保持低 60 ms，循环六档（0档停机，1–5档运行）。原图 PA3 是 MCU_VF/VSR/ESC 输入，并非已标注按键；实验时先断开原电位器/PWM 输入。此软件开关不是独立急停。
- 启动经过低侧自举、对齐、旋转 Id 电流启动。反电势幅值、PLL 质量、正向速度、负载角有界稳定及速度一致性连续达标才接管；没有固定延时冒充闭环。
- 故障锁存到 MCU 复位，按键不会自动重试。停止请求仍在下一次真实 reload 关桥。不要对旋转电机执行本例自举/对齐。
- 当前本地为 3S，欠压 9.9 V；仓库基线原默认为 2S／6.6 V。不自动识别电池，不在欠压时降档。16 V 过压和 1.8 A 软件跳闸；当前对齐/启动/运行指令上限为 300/500/1100 mA。
- 3.3 V/节是实验起点，不是对未知电芯的安全结论，也不能发现单节失衡或代替 BMS。电池门限不证明 EG2163 VCC、LDO5 或 MOS 门极供电合格。
- 每个已解锁 ADC 样本立即检查电源轨、原始过流门限和离散模拟看门狗。两个 mA 换算共用采样时 VDDA，并在 ADC2 更新比例前完成。重建后再检查相电流。供电异常在进入 RL 加权运算前关断，Off/Calibrating 仍允许未接母线。
- 外加对称 1 µs 死区、AOE=0、OSSI/OSSR=1、OIS/OISN=0。故障先关 MOE、停 ATIM 及 ADC 触发，再禁用高频 IRQ。没有已验证的独立过流→ATIM BK 连线或过温保护，必须保留外部限流和断电措施。

## 本版为何改为 4 kHz

上一版 8 kHz EAU 台架记录 `site=4 start=4096 observed=1000 reload=true elapsed_min=8904 stage=5`。该次控制可用 7304 tick，却至少消耗 8904 tick；最差合法采样位置只有 5822 tick。故障在首次 Align 计算，实际帧仍为 Bootstrap，尚未包括正常电流运输和 OpenLoop 观测器，不能只削掉约 1600 tick 就宣称预算充足。

本版同时处理调度、数学和代码生成成本：

1. PWM/控制为 4 kHz，每帧 24000 tick。保留 700 tick reload 截止、128 tick 采样容差、960 tick 双窗口和距下一帧 600 tick 的控制退出余量。
2. 所有三相占空比共同平移，使最小比较值固定为 DUTY_MIN。相间电压和有效矢量时长不变，采样尽量提前；真实零矢量位置仍纳入观测模型。
3. 采用实际 PWM 边沿的指数加权 RL 模型，同时修正首样本到第二保持时刻的电流运输。旧端点电流梯形近似在降低频率时会误估电阻压降，不能只改 ARR 和增益。
4. 启动时通过窄 FLASH HAL 接口使能预取/缓存，带 KEY 写入并回读。96 MHz 必需的三等待周期不变；07 永久保留 FLASH 单例、不执行擦写，01–06 不启用此新接口。启动日志显示修改前状态。
5. EAU 的内部操作描述内联到一个共享热入口，消除原两层函数及 Operation/Result 搬运，避免各调用点复制故障关断代码。标称 dt 和严格 KCL 的恒等运算直接返回；有符号常量 32768 除法由编译器生成精确移位运算。没有软件除法回退或近似母线倒数。

Flash 缓存命中、总线等待和芯片乘法延迟没有实板 WCET 证明。指令数减少、模型通过和更大的安排时隙都不是台架达标证明；运行时 deadline 仍负责失败关断。

## 定时、采样与帧身份

96 MHz，ATIM PSC=0、ARR=23999、RCR=0，边沿对齐 PWM1 CH1–3；内部 PWM2 CH4/5 通过 MMS2=26 触发 ADC1。ADC1 ENS=0/CONT=0，单槽 CH8，每次触发仅一次转换；ADC=PCLK/2=48 MHz，70 周期采样+15 周期转换。保持时刻为触发后 140 tick，EOS 为 170 tick。

- 死区 96 tick；首下降沿后等待 480 tick、第二下降沿后等待 240 tick；有效矢量至少 960 tick（10 µs）。首样本480+170+128=778 tick、第二样本240+170+128=538 tick，均小于窗口。每个样本分别检查时刻、顺序和 UIF，不能凭一个 EOS 假定没有覆盖。
- 比较值范围 2400–12000；初始比较值 [2400,3360,4320]，触发 [2880,3600]，接受读数区间 [3050,3178]、[3770,3898]。
- 预载/解锁必须 CNT≤700，控制全部完成必须 CNT<23400。最晚合法第二样本读取为 11578，保留 11822 tick（约 123.1 µs）；这是最坏采样位置的安排预算，不是已测耗时。最小窗口初始帧则有 19502 tick 可用。
- 最早下降沿为 2400，首触发 2880，EOS 3050，均晚于原 reload 截止。首次启桥作用于三相 CCR=0 的 Bootstrap 帧，随后 FOC 通过真实 reload 切换。
- 五路 CCR 均预载：reload 先将旧 staged 晋升为 active，再将 pending 写入预载。ADC 只使用 active 的相序/波形；新计算仅进入 pending。禁止运行时 UG/UDIS 拼凑更新。
- ATIM/ADC1 同为 P0，不嵌套，EAU 只由 ADC1 使用。没有让原共享状态跨 reload 继续计算，也没有额外消息队列。命令约两帧流水线延迟，4 kHz 时为 500 µs。
- ADC2 上电先启动一次，此后每 1 ms（4 帧）发起；3 ms（12 帧）未更新即故障。仅初次就绪前且 MOE、软件解锁状态及全部流水线计划均为关闭时，允许无效 BGR/VDDA 在同一 3 ms 预算内重采样；无效值不刷新帧龄、不参与零点校准。工厂标定无效立即故障，首次合格后的 BGR/VDDA 异常也立即故障。速度环 100 Hz（40 帧），诊断内存每 50 ms（200 帧）。零点 2048 样本，约 256 ms。

## RL 观测与参数

两个电流样本分别对应首降相的负电流和末降相的正电流。首降相在两次保持之间先受 -2Vbus/3，再受 -Vbus/3；使用这两个真实区间、配置的 R/L 和上一轮反电势作指数运输，最后由 KCL 得第三相。

RlInterval 显式包含 dt、a=exp(-R·dt/L) 和指数加权电压响应 W。每段导通 [s,e] 对 W 的贡献为 Vbus·[exp(-R(T-e)/L)−exp(-R(T-s)/L)]，分别积分前帧尾部及本帧头部，再转为 αβ。观察器按 e=[W+R(a·i0−i1)]/(1−a) 逆解，不再把端点电流平均当区间电流平均。模型假定区间内反电势近似恒定；PLL 相位补偿使用指数权重的时间重心。

衰减表由配置 R/L 在编译期计算，运行时仅 Q15 查表/线性插值，没有浮点或运行时宽整数除法。参数校验约束中间乘积范围；修改 R/L、频率或保护上限后必须重新验证，不能仅通过编译判断模型有效。

50 Hz 名义电流环采用 Q15 Kp/Ki=9008/8622；PLL=10240/100。反电势滤波为 18/64，近似保持原 8 kHz 的物理时间常数；电流爬升 2 mA/帧仍为 8 A/s。自举、对齐、启动超时、资格、失锁、失速和混合时长按 CONTROL_HZ 保持原物理时间。该次 4 kHz 重预算没有调整资格门限；本次负载角资格重构另见下节，不能再把旧 ±30° 判据视为现行规则。

强制可测窗口与较低 PWM 频率仍产生瞬时电流纹波。实际死区、管压降、模拟建立、采样偏差、参数误差和磁饱和不在理想模型中，软件观测器不能代替标定或硬件保护。

## 启动后 9 号故障与电压余量

实板已能平顺加速，但 5 s 内未连续满足接管资格而锁存 StartupTimeout。转动和声音都不能证明已闭环；该次 `TIMING site=0` 不是 13 号时序故障。新日志保留实际故障前状态及其帧龄，不再因控制器先进入 Fault 而把 `state_before` 错记为 7。

按用户给出的 500 mA 台架试验上限，上版已将旋转启动电流指令从 200 mA 调到 250 mA，本版保持该值；对齐仍 150 mA，运行上限仍 250 mA，原始/重建过流保护仍 750 mA，未提高电压矢量或任何接管门限。**指令不是物理瞬时相电流上限，750 mA 软件跳闸也不能保证相电流不超过 500 mA。** 必须通过外部限流和电流测量控制试验风险。7.907 V 母线下矢量限制约 1.568 V；500 mA 的相模型电阻压降已达 1.675 V，尚未计反电势和动态压降，因此不能直接设到 500 mA。

本次 250 mA 台架在 7.907 V、25 Hz 仍超时：`reject=0 good=40/1000 best=125` 仅证明最后 10 ms 合格、历史最长 31.25 ms，不能证明整个 250 ms 连续合格。`previous_vdq=[1098,1118] mV` 的长度约 1567 mV，已触及 1568 mV 电压圆；估计反电势 1140 mV、强制角差约 -29.4°。按该估计作稳态旋转 d 轴预算，250 mA / 25 Hz 需要约 1.75 V，超过可用值。该预算不是把不同帧的瞬时采样电流、反电势和未来 PWM 命令强行视为同一稳态测量。

默认 I/F 平台由 25 Hz 降至 **18 Hz 电气频率**，仍在 2.5 s 内从 2 Hz 加速，原 5 s 超时不变。以本次估计磁链作预算，18 Hz / 30° / 250 mA 需要约 1.46 V，7.907 V 母线下留约 0.11 V 理想余量。15 Hz 虽留更多电压，但旧模型假定磁链 0.005 V·s 时反电势仅约 471 mV，会达不到原 500 mV 门槛；18 Hz 是兼顾两种估计的台架起点。该余量不覆盖未知死区、器件压降、负载或整个 2S 电压范围，不是自动电压调速，也不保证实板成功。

前一版 18 Hz 修改保留了原 ±30° / PLL 逐点接管规则；本次新证据表明需要区分负载角与观察器质量，现行资格及过渡见下节。最终速度目标仍 25 Hz，运行可用转矩受实际电压余量限制。理想开关模型在本次估计磁链、7.907 V 下仍可能出现约 0.51 A 瞬时相峰值，不能把较低启动频率当作 500 mA 硬限流保证。模型没有重现真实台架的全部失效轨迹；需限流空载复测。

故障关桥、停 PWM/ADC 高频源后一次性输出 HANDOFF / HANDOFF_HISTORY / OBSERVER：

- `state_before` / `age` 是故障前控制状态和该状态已执行的帧数；OpenLoop=4，当前启动超时为 20000 帧。
- `reject` 是同一失败帧全部未通过资格的位掩码：1 未开始跟踪，2 滤后幅值低于 500 mV，4 PLL 峰值、RMS、连续异常或窗口异常数量超限，8 速度非正，16 超速，32 低于 8 Hz，64 负载角走廊/窗口峰峰变化超限，或最终帧仍要求负向 Iq，128 强制速度差超限。多个值相加；0 但 `good<1000` 表示当前帧合格、连续时间仍不足。
- `good` / `best` 分别是当前和本次启动最长连续候选合格帧数；只在恒速平台累计，要求 1000 帧（250 ms），任一拒绝清零，不能跨窗口凑数。`forced` / `pll` 是电气 mHz，角单位为一周 65536。没有已知极对数时不要换算为机械 RPM。
- `HANDOFF_HISTORY plateau_frames` 只统计 OpenLoop 加速结束后（`age>10000`）的帧；若一直到 5 s 超时，分母恰为 10000。`reject_counts_bits1_to128` 按上述 8 个位分别计数，同帧可失败多个门，计数之和可大于分母。它不包含加速段；`last_reject/age/delta/pll_error` 则保留整个 OpenLoop 最后一次拒绝，即使故障帧 `reject=0` 仍可追溯最近断串。后续 Blend/ClosedLoop 不再更新此历史。
- `raw_unclamped_ab` 是本帧 RL 逆解后、幅值钳位及低通前的 αβ 反电势；`filtered_ab` / `magnitude` 是滤后数据。它们是模型估计，不能当作独立转子角/转速传感器。
- `phase` 是本帧重建电流；`previous_dq/target/vdq` 是故障前最后一次完成的电流控制，故障帧在接管检查失败后没有再运行 PI。`vlimit` 用本帧母线计算。两帧 PWM 流水线意味着 `previous_vdq` 也不是故障帧的真实施加电压。
- 仅在 OpenLoop 增加资格位和有界整数计数、最后拒绝的几个标量；详细诊断只在关断后合成，运行中不增加 RTT 或周期大块快照。可读取 `FOC_CONTROL_FAULT`，同样必须先物理断开功率再 halt。

若反电势不足，应先核对磁链/速度和电压余量；若角度或 PLL 不合格，应先核对相电流极性、相序、R/L、模拟建立及死区。不要凭 9 号故障继续加电流、延长超时或放宽锁定条件。冷上电未按键即两闪是 Calibration，须看 CAL 原因，不能与此运行后故障混为一谈。

## 18 Hz 台架后的负载角资格与无跳变接管

7.899 V / 18 Hz 台架仍触发 StartupTimeout：10000 个平台帧中，旧角门拒绝 1900 帧，旧逐点 PLL 门拒绝 159 帧；最长连续合格 129 帧，仅 32.25 ms。结束时 `observer-forced=-5237`（约 -28.77°）、最后拒绝为 -5586（约 -30.69°），不是时序故障。此时电流已接近 250 mA 指令，所以降速留电压余量没有解决全部原因。

旋转正 Id 启动中的强制角是**电流轴**，观察器估计的是**转子磁链轴**。正转带转矩时前者应领先后者；理想 250 mA / 28.77° 负载角对应转子 Id≈219 mA、Iq≈120 mA。不能把该负载角全部当成观察器误差，也不能由本日志证明估计角就是真实转子角。R/L 误差、死区、器件压降、ADC 量化与错时运输仍会产生偏差。正向 EMF 的 atan2 符号与 Park 约定一致；现有滤波/指数时间重心补偿在 18 Hz 的小信号近似误差约 0.02°，不支持随意增加 30° 固定补偿。

现行资格明确改变了旧规则，且仅在 2.5 s 加速结束后的恒速平台累计：

- 保留反电势至少 500 mV、正向/最低/最高速度和原强制速度差检查。没有将强制角输入观察器制造锁定。
- `observer-forced` 必须在 [-60°, +10°] 走廊，固定候选窗口内最大值减最小值不超过 20°；窗口中心不跟随漂移。实际进入 Blend 的第 1000 帧还要求差值不为正，以免把负 Iq 截为零而改变电流矢量。
- PLL 逐帧绝对残差不超过 20°；累计前缀 RMS 不超过原 10°；连续超过 10° 不得达到 4 帧（1 ms）；整个 1000 帧最多 50 帧超过 10°。这些是新的有界噪声容忍规则，不等价于旧逐点 10° 限制。每次拒绝全部清零，原 5 s 超时不延长。
- 20°/250 ms 变化界限仍可允许约 0.22 Hz 以下的缓慢相对漂移；它是有限窗口一致性检查，不是独立转子角精度或机械同步证明。60° 上限留下距旋转电流轴 90° 边界的余量，也不能排除恒定观察偏差。

接管帧先完成原强制坐标系 PI 和电压圆限制，**原样返回本帧 αβ 电压**；再将电流指令、有界电压及测得电流重表达在观察器坐标系，按 `I=V−P` 初始化电流 PI。不能只旋转可能已饱和的积分量。跟踪初始化若因抵消 P 而略越普通积分边界，允许它向内消退，禁止继续向外增长；最终电压圆仍始终生效。没有突变物理电流参考来把负载角设成零。

随后 0.5 s Blend 只淡出观察器坐标系的 Id，速度参考保持接管时的估计速度；结束后才按原速度斜坡向 25 Hz 加速。速度环的 Iq 额度按剩余 Id 的电流圆计算，并对 Blend 的完整电流参考再次限圆，避免原“Id 尚未消退但 Iq 单独达到 250 mA”产生超过 250 mA 的指令矢量。这仍不是瞬时相电流硬上限；原 750 mA 跳闸、供电、失锁/失速与时序保护保持，4 kHz 不变。

停机后的 `HANDOFF_COHERENCE` 新行提供平台角差最小/最大/平均值、原始 PLL 峰值及超 10° 帧数、当前窗口范围/均方，以及最后一次失败窗口的帧数、范围、均方与异常帧数。均方单位为角单位平方，开平方后乘 360/65536 可换算 RMS 度数；固定点累计先去掉平方的低 8 位。`HANDOFF reject` 现在保存实际执行过的完整判据，不会把仅因窗口 RMS/变化失败的帧错报成 0。详细打印仍只在停桥之后。

软件边界测试与开关机械模型支持该转移实现；模型不能完整重放未知的真实台架轨迹。组合R/L与ADC/压降误差的敏感性模型即使通过窗口，仍出现约25°绝对角误差和约624mA瞬时相峰值，进一步说明本软件不能保证500mA物理峰值。低磁链/高惯量等情况可能被更严格的稳定性窗口拒绝，不为使模型通过而延长超时。限流空载复测时仍须保留完整故障日志和外部电流测量。理论依据：[Imperix I-f 启动与过渡说明](https://imperix.com/doc/implementation/i-f-startup-method)。

## LED 与首故障日志

PC13 常亮表示软件已解锁，熄灭表示未解锁；不能证明转子转动或门极安全。故障每闪亮/灭各 200 ms，整组后额外灭 1.6 s。闪码：1 参数、2 校准、3 样本无效、4 样本/慢 ADC 超时、5 过流、6 欠压、7 过压、8 失锁、9 启动超时、10 失速、11 超速、12 驱动、13 时序、14 EAU 算术错误。

标准 defmt-rtt 非阻塞输出仅在启动前和首故障关桥停触发后进行；高频 ISR 不打印。保留完整 `07 fault`、`ADC`、`TIMING`、`CONTROL` 和可能的 `HANDOFF`、`OBSERVER`、`CAL`、`EAU error` 行。RTT 缓冲区满可能丢日志。

- BGR 工厂值在启用 Flash FETCH/CACHE 前读一次并传入电机任务。启动日志打印 `before_accel` / `after_accel`，两者都来自 0x001007D2 的原始 u16/mV；仅使用 `before_accel`。直接复位时原 FETCH/CACHE 必须均关闭，否则停在启动检查，不接受无法证明来源的数值。开启后读数仅作诊断，不代替工厂值。10240（0x2800）仍无效，不回退到 1200、不放宽标定范围。
- CAL reason：1 零点越界，2 噪声超限，3 工厂标定无效，4 BGR 原始值为零，5 计算 VDDA 超出 4.5–5.5 V，6 就绪前输出未全部关闭。raw_bus/raw_bgr 是 ADC2 原始值，factory_mv 是工厂半字，candidate_vdda 是此次计算值；首行 vdda 仍为上次已接受值或上电名义 5000，不能用它替代 candidate。ready 表示已经有过有效供电样本，samples/min/max 用于区分零点校准；原始母线饱和仍立即过压关断。
- ADC reason：1 跨 reload，2 多余样本，3 过早，4 过晚，0 其他。entry 是入口 CNT，read 是 RESULT0 读取/确认后的 CNT；保护检查 read，不用更早 entry 放宽判定。
- TIMING site：1 reload 入口、2 预载完成、3 解锁末尾、4 第二样本分段检查、5 输入 dt。合法 dt 为 12000–36000 tick。state_before 是故障前状态：0 校准、1 Off、2 Bootstrap、3 Align、4 OpenLoop、5 Blend、6 ClosedLoop、7 Fault。
- CONTROL 五段依次为电流/供电换算、错时重建、RL 区间、电流控制/观察器、调制/计划/诊断。last 是本帧，max 只包含通过截止的段；故障段可能只是下界，未执行后续段为 0。
- UIF 无法计数多个周期，elapsed_min 只给保守下界；不要按 u16 的 65536 回绕计算 PWM 周期。max_control/max_update 不包含完整异常入口/退出，不能当 WCET。
- EAU 检查 BUSY/ZERO/OVR，每次最多 64 次状态读取。任何错误在返回占位值前立即关 MOE、停 ATIM，然后锁存 14；不继续提交计划。错误子码 1 除零、2 溢出、3 忙、4 轮询超时、5 零预算。

具名 FOC_DIAGNOSTICS 可供调试器读取，但须先物理断开功率再 halt；CPU 暂停时 PWM 可能继续运行，不能带功率靠断点排故。

## 硬件映射与量纲

| 用途 | 映射 |
|---|---|
| 三相上桥 | PB5/PB6/PB7，ATIM CH1/2/3，AF7 |
| 三相下桥 | PA15/PB3/PB4，ATIM CH1N/2N/3N，AF7 |
| 快速母线电流 | PA6 OPA1 INP2、PA7 INN2，PB0 OPA 输出/ADC1 CH8 |
| 母线电压 | PA8，ADC2 CH5，10 kΩ/1 kΩ 分压 |
| 参考电压 | ADC2 CH15/BGR，工厂校准半字 0x001007D2 |
| 运行输入/LED | PA3/PC13 |

R17/R18=1 kΩ、R19=10 kΩ、R20/R21=20 kΩ，理想输出 2.5 V+10×Vshunt。实际 10 mΩ 对应约 100 mV/A，5 V/12 bit 约 12.2 mA/LSB；正电流从桥低端 IS 经 R0 流向 GND。VDDA 允许 4.5–5.5 V。PB2 慢平均电流和 PA0/1/2 六步相电压不参与本例闭环。R0 功率、MOS 型号和板子额定值尚未确认。

## 构建与台架验收

必须 release 构建；源码不附测试目录、额外 example feature 或 CI。工作区根目录执行：

```sh
cargo run -p xtask -- regenerate
cargo build --release --target thumbv6m-none-eabi -p cw32-bldc-07-sensorless-foc
```

1. 断开功率，检查复位/引脚极性、PB0 零点、BGR/VDDA/母线比例；确认启动日志 Flash wait=3、原预取/缓存关闭且回读已启用，并保留 BGR `before_accel` / `after_accel` 两个原始值。
2. 使用低压限流、空载电机和独立断电保护，确认驱动 VCC、5 V、MOS 门极、死区、双采样位置与电流符号。
3. 测量完整中断延迟和首样本占用；覆盖 Align、OpenLoop、Blend、ClosedLoop、速度环/ADC2/诊断重合帧及限幅路径，不能只看 Align 成功或历史最大值。
4. 验证 Id/Iq、方向、资格接管以及停止/失锁/过流/电压/漏采样/超预算关断。不能用“编译或模型通过”替代实板验收。

外部定点/开关机械模型和 ARM 构建结果见[验证记录](../../../docs/validation-sensorless-foc.md)。依据包括用户 BLDC_SCH.pdf、[CW32L012 RM1.4](https://www.whxy.com/uploads/files/20260603/CW32L012_UserManual_CN_V1.4.pdf) §§4、7、11、17、25 和 EG2163 官方数据手册。

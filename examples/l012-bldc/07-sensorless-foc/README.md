# 07：单电阻无感 FOC（独立实验例程）

面向用户给出的 CW32L012C8 电机板。实际 R0 为 **10 mΩ**，覆盖原理图标注的 2 mΩ。01–06 仍是原工程六步换相例程，本目录不导入它们的业务源码。

本例实现三相电流重建、Clarke/Park、Id/Iq PI、可测量窗口 PWM、反电势电压模型和 PLL，以及有资格门槛的开环启动 → 角度渐变 → 无感闭环。不是把六步过零或固定时间开环改名为 FOC。

**未实板验证，不是通用电机即插即用固件。** 已采用用户给出的任意两根电机线间电阻 6.7 Ω、静态电感 1.75 mH；按平衡等效星形暂用相模型 R=3.35 Ω、L≈875 µH。静态电感受转子位置、测量频率、互感和凸极性影响，仍需动态验证。PI、启动速度、电流和母线范围是实验初值。R/L 不正确、低电感引起的电流纹波、ADC/门极时序或 CPU 预算不满足时，应拒绝切入闭环或故障停机，不能保证空载/带载启动成功，更不支持零速有载无感闭环。

## 默认行为

- 普通构建直接包含功率输出和无感接管，不需要额外 feature 或确认常量。上电先保持六个输出低电平，完成母线/零点测量后等待手动启动，不在上电时自动转动。
- PA3 连续释放 60 ms 后，再保持低电平 60 ms，切换启动/停止。启动后经过低侧自举、对齐、旋转电流启动，满足观测器资格才接管无感闭环。任一故障锁存到 MCU 复位，不自动重试。
- **原理图 PA3 是 MCU_VF/VSR/ESC 输入，不是已标注的板载按键。** 本例把它用作手动开关协议；试验时断开原电位器/PWM输入、接好高电平释放/低电平按下的手动输入。不能把此软件输入当独立急停。
- PC13 LED 常亮表示软件已解锁桥臂；故障按下表循环闪码，每闪亮 200 ms、灭 200 ms，整组结束后额外灭 1.6 s。熄灭表示未解锁。它不能证明转子在转或门极安全。
- 07 使用标准 defmt-rtt 非阻塞日志：只在启动定时器前输出配置，首次故障关桥并停止高频采样触发后，由普通 I/O 任务输出一次诊断。运行中的高频 ISR 和每帧控制不打印；没有自建日志模块。01–06 保持原样。
- 调试数据是 `hardware::FOC_DIAGNOSTICS` 的具名字段。先物理断开功率，再 halt 检查；不能带功率靠暂停 CPU 排故。PWM 在 CPU halt 时可能继续运行。

## LED 故障码与首故障日志

数清两次长停顿之间的闪烁次数；记录首个锁存故障，复位前不会被后续故障覆盖。

| 闪烁次数 | 故障 | 排查方向 |
|---|---|---|
| 1 | Parameters | 配置参数不合法或电流阈值超出 ADC 范围 |
| 2 | Calibration | PB0 零点/噪声、工厂 BGR 校准值或 VDDA 4.5–5.5 V 检查失败 |
| 3 | SampleInvalid | ADC1 样本到达时刻/顺序异常，或运行电流重建无效 |
| 4 | SampleTimeout | ADC1 双样本/待提交帧缺失，或 ADC2 测量超过 24 帧（3 ms）未更新 |
| 5 | OverCurrent | 运行电流、ADC 电源轨或模拟看门狗超限 |
| 6 | UnderVoltage | 启动/运行时母线低于所配置串数的门限，默认 2S 为 6.6 V，3S 为 9.9 V |
| 7 | OverVoltage | 启动/运行时母线高于 16 V，或 ADC2 母线接近满量程 |
| 8 | ObserverLost | 无感接管后观测器失去资格 |
| 9 | StartupTimeout | 开环启动没有在期限内满足接管条件 |
| 10 | Stall | 闭环失速 |
| 11 | Overspeed | 闭环电角速度过高 |
| 12 | Driver | ATIM 故障旗标或 MOE 意外关闭 |
| 13 | Timing | PWM 预载/解锁、ADC 控制计算或帧间隔超出原有时间边界 |

上电未按 PA3 就闪码时，先记录次数，不要反复启动。此时仍会检查 ADC、偏置和中断时序；单纯未接功率母线不会在 Off/Calibrating 状态触发 6。2 号同时涉及模拟 5 V 电源，不能把断开电机母线和断开模拟电源混为一谈。若需暂停调试器读取具名诊断字段，先物理断开功率；带功率暂停 CPU 不安全。

### 3 号故障的精确证据

`cargo run --release` 会通过板级 runner 显示 RTT。保留首次 `07 fault=...`、`ADC sample=...` 和 `TIMING site=...`，另外两行解释 reason/site。不要在高频 ISR 内补打印来追查，否则日志本身可能扰动 1.33 µs 的判定预算。

- `sample` 是本帧的 0/1 样本序号；2 或更大表示多余样本。
- `reason`：1=更新旗标未处理（可能跨帧），2=多余样本，3=过早，4=过晚，0=故障来自其他保护。
- `entry` 是进入 ADC 处理函数后尽早读取的 CNT；`read` 是 RESULT0 读取和 EOS 确认之后的 CNT。保护仍检查 `read`，没有用更早的 `entry` 放宽边界。
- `expected` 是原来的转换完成到 +128 tick 接收区间；当前 8 kHz 初始帧两次分别为 3050–3178、4010–4138。`raw` 是这次故障对应的 ADC 原值，`trigger` 是当前帧的两个硬件触发计数值。
- `received` 记录最近两次已接受的读数时刻；`previous_end` 是前次 ISR 返回前的计数，`max_first` 是已观测首样本处理耗时最大值。它们不包含最终函数返回/异常退出的全部耗时，不能当作 WCET。

故障先清 MOE、停 ATIM 计数/更新中断，再禁用 ADC1/ATIM NVIC，阻止后续 CH4/5 ADC 触发；不会清除 ADC/ATIM 故障旗标。BTIM1 的 1 ms 唤醒保留，普通任务只输出冻结的首故障快照，需复位才会重新采样。非阻塞 RTT 缓冲区满时可能丢日志，建议通过 `cargo run --release` 从复位开始连接。

未解锁期间仍逐样本检查时序并累积 2048 个零点样本。解锁后，每次采样仍立即检查电源轨、精确等价的原始 ADC 过流门限和模拟看门狗；两个 mA 换算除法放在第二次样本之后、ADC2 更新 VDDA 之前。没有跳过首样本电流保护，也没有放宽 128 tick 接收容差。尚未测得新版真实中断延迟，不能仅凭编译通过断言 3 号故障已解决。

### 13 号故障的精确检查点

- `site`：1=ATIM reload 入口已晚，2=五路 CCR 预载写完，3=解锁/更新路径末尾，4=第二样本控制计算末尾，5=控制器输入的两次保持时刻间隔异常，0=本次不是 Timing 故障。
- `start` 是本次 ISR 的检查起点，`observed` 是故障检查实际读取的 CNT，`limit` 是原有截止点，`reload` 是该检查读到的 UIF；`samples` 是当时已接受样本数。site 2/3 的 samples 已因 reload 归零，不表示前帧漏采样。site 5 的 observed 改为帧间隔 tick，合法范围是 6000–18000。
- site 1–3 仍要求 CNT≤700；site 4 要求 CNT<11400（距下一帧保留 600 tick），并拒绝计数回绕或未处理 reload。样本接收容差仍是 128 tick。`observed-start` 可区分处理耗时与入口已经延迟，但不包含完整异常入口/退出。
- `max_update` / `max_control` 只表示已记录的检查点间耗时；当前失败路径的准确数值以 site/start/observed 为准，不能把历史最大值当作失败时刻。
- `state_before` / `armed_before` 现在对所有首故障保存关断前状态（旧版非 Timing 故障的 0/false 没有此意义），避免把故障处理后的 `state=7 armed=false` 误判成一直未启动。state 编码为 0=校准、1=Off、2=Bootstrap、3=Align、4=OpenLoop、5=Blend、6=ClosedLoop、7=Fault。

实板旧日志 `received=[2802,3405] previous_end=5814 frame=1` 表明两次采样已接受，且最近 ADC 末尾计数低于 9000；仅凭旧日志不能区分 ATIM 的三个检查点或 UIF 条件。为缩短 reload 路径，前帧备份和调制器复位移至第二样本尾部，待机时不再反复重建已准备好的 Off 计划；启动/停止请求仍在 reload 处理，五路 CCR 流水线身份不变。每个故障分支关断后立即返回，避免冻结快照后继续写预载或计算。仍须用新日志或台架测量确认，不把此优化宣称为实测时限已满足。

随后用户确认 `site=2 start=110 observed=989 limit=700 frame=57071` 发生在按键之后，不是待机随机故障。旧 ARM release 的按键边沿路径在 CCR 预载前调用两次 `__aeabi_memclr4` 批量复位 PI/观测器；正常待机不会走这两次调用。现 reload 仍即时接受启动/停止状态，停止仍即时关桥，但只标记待复位；第二样本后的控制计算先执行完整复位，再产生新计划。首个启动帧仍是 Off，Bootstrap 计划只能在复位完成后产生，因此没有把未复位的控制状态交给功率输出。诊断在此间仍按复位后的零命令/估计值呈现。

此前 10 kHz ARM release 已确认 ATIM 不再含批量清零调用；700/9000/128 tick、逐样本保护、故障锁存和手动启动不变。这消除了已发现的按键路径额外工作，但尚不能证明实板最坏时延达标，也不能把调试探针、Flash 或总线等待认定为根因。

后续 `site=3 start=110 observed=740 limit=700 state_before=2 armed_before=true` 表明已到 Bootstrap 的首次解锁末尾；`armed_before` 是故障关断前的状态，不代表整次 ISR 入口已解锁。正常已解锁帧不会重复写 MOE。当时 10 kHz 版本保留原检查位置及 700/9000/128 tick：将固定 CH1–3 预载迭代器改为同序全字直接写入，去除 ARM `opt-level=s` 生成的栈副本/循环；解锁条件去掉此前状态归一化已经保证的 Fault 重复读取。硬件故障前检、MOE 写入后的故障/MOE 回读和所有失败关断均保留。

首次 Bootstrap 解锁成功路径由 230 降至 205 条 Thumb 指令，入口与解锁末尾 CNT 读取之间由 177 降至 153 条；ATIM 局部栈由 68 降至 36 字节。没有把状态复制或诊断挪到检查点后以缩短账面时间。指令数不等于实板 tick，仍须按原 700 tick 截止重新验证，不能据此保证消除这 40 tick 超限。

## 当前 8 kHz 调度与首样本预算

后续旧版台架日志 `sample=1 entry=3608 read=3646 expected=3290..3418 previous_end=3533 max_first=764` 表明首个 ISR 尚未结束时，第二样本的服务截止已经过去。`previous_end` 在这个分支是同帧首样本末尾，`max_first` 是历史最大值；不能把两者自动当作同一次精确测量。frame=44050 已远晚于第 2048 个校准样本，且已解锁首样本 ARM 路径仍含软件电流除法。旧版 site=0 的 state_before/armed_before 是默认值，不能证明故障前处于校准或未解锁。

当前 PWM/控制从 10 kHz 降到 8 kHz，帧长 12000 tick；真实双样本间隙从 576 增到至少 960 tick（10 µs），不是只加大 ARR。首样本逐次保护改为精确等价的原始 ADC 比较，mA 换算留到第二样本后。最终 ARM 正常已解锁首样本外层路径为 115 条 Thumb 指令、无函数调用，旧路径为 131 条并调用一次软件除法；这里不把指令数等同于实测周期。

- 保留 700 tick reload 截止、128 tick 采样接收容差、96/240/140/170 tick 死区/建立/保持/转换时间；控制截止随新帧长变为 11400，仍给下一帧保留 600 tick。
- 电流 PI、PLL、反电势滤波与群延迟补偿、速度单位换算一起重算；100 Hz 速度环、1 ms ADC2、3 ms ADC2 超时、启动和失锁时长不因降频变慢。电流命令仍每帧递增 1 mA，即从 10 A/s 稍降至 8 A/s；零点仍取 2048 个样本，现约 128 ms。
- 对照验证发现 5 kHz 使原有观测器对开关纹波的梯形电阻压降近似出现更大误差，多个负载模型未通过原有资格门槛，因此未采用。没有调低反电势/角度/速度资格或延长启动超时来掩盖失败。
- 8 kHz、10 µs 窗口的最终定点模型已重新检查轻载 8/12/16 V、高惯量 12 V、重负载和堵转；模型结果与未实测项目见验证记录。低频使脉动和两帧延迟增加，软件仿真不能保证实际硬件启动或最坏中断时限。

## 模块和任务

- `main.rs`：时钟、实际中断绑定、平铺的 `MotorResources` 交接。
- `hardware.rs`：ADC/OPA/PWM 初始化、零点校准、帧身份、同步 ISR、即时关断。
- `sampling.rs`：两个有效矢量窗口、占空比位移与误差补偿、母线单电阻重建。
- `control.rs`：纯定点控制与状态机，没有寄存器或 unsafe。
- `config.rs`：集中实验参数与边界校验。
- `io.rs`：标准 Embassy 线程任务，只做手动输入消抖与 LED。

`motor_task` 保留外设单例并初始化后挂起。P0 的 ATIM 和 ADC1 中断同级、不互相嵌套；完整双样本后的电流控制在 ADC1 ISR 同步执行。BTIM1/P3 只发出 1 ms I/O 唤醒。没有软件中断执行器、每毫秒运行的电机闭环、通用 runtime 或额外消息队列。I/O 线程在高频源已停止后负责首故障日志。

## 双采样与完整帧一致性

96 MHz，ATIM PSC=0、ARR=11999、RCR=0，边沿对齐 8 kHz。CH1–3 是互补 PWM1，CH4/5 是内部 PWM2（不复用到外部引脚）。RM1.4 §17.10.2（印刷页 372–373）的 MMS2=26 表示“OC4REFC 上升或 OC5REFC 上升”，ADC1 只打开 TRGO2 触发。

ADC1 `ENS=0/CONT=0/SQRCH0=8`，每个独立触发只转一次 PB0。每次转换 70+15 个 48 MHz ADC 时钟，约 1.771 µs，满足 1 MSPS 上限。它不是一次触发连续扫描两槽。

设三相 PWM1 比较值排序为 `d0 < d1 < d2`：

1. 首个下降沿后两个上桥仍导通，`Idc1 = -I首降相`。
2. 第二下降沿后只剩末降相上桥导通，`Idc2 = I末降相`。
3. 利用配置的 R/L、上一轮反电势估计和两个 ADC 保持时刻间的理想开关电压积分，将首降相电流预测到第二保持时刻；最后用 KCL 重建第三相。ADC 保持时刻按触发后 140 tick，而不是 EOS 的 170 tick 处理。

每个有效矢量至少 960 tick（10 µs）。下降沿后等待 240 tick（2.5 µs）再采样；转换为 170 tick；允许 ISR 读取延迟 128 tick。三者合计 538 tick，必须小于窗口，且每个样本分别检查其预期时刻、顺序和更新旗标。ADC 没有 OVR，不能凭一个 EOS 推断期间只转过一次；迟到、覆盖嫌疑、缺帧或额外样本均锁存停机。

所有五个 CCR 开预载。每次真实 reload 后，软件先把上一批 `staged` 晋升为 `active`，再把已算好的 `pending` 写到五个预载寄存器供下次 reload 使用。ADC 只配对 `active` 的相序和实际电压，算完的新结果只进 `pending`。CCR5/6 使用 PAC 的 `ccr_group`，不是越界的 `ccr(4/5)`。

写入及解锁必须在 CNT≤700 完成，第二样本控制必须在 CNT<11400 完成；慢速 ADC2 每 1 ms 发起、3 ms 未更新即故障；VDDA/母线换算也放在第二样本后的时隙，避免两次软件除法占用 CCR 预载预算；计数回绕/UIF/未完成采样均导致关断。运行时不使用 UG 或 UDIS 去拼凑“原子更新”。电流计算出的命令到物理应用约有两帧（现在 250 µs）流水线延迟，应按它整定电流环。PWM 比较值限制为 1200–6000 tick，最晚第二样本读取为 5578 tick，距离控制截止点至少约 60.6 µs；这只是安排的预算，不是实测 WCET。

700 是保守的软件服务截止，不是从日志拟合的新门限：当前 8 kHz FOC 最早下降沿为 1200，最早 ADC 触发为 1440、转换完成为 1610 tick，分别留有 500/740/910 tick。首次启桥实际作用于三相 CCR=0 的 Bootstrap 帧；之后进入 Align/FOC 时 MOE 已开启，由真实 reload 切换波形。软件帧身份、五个预载和首次解锁都仍在原检查点之前；检查之后仅原有统计/状态发布及中断退出。这些间隔是调度余量，不是总线等待、死区传播、异常退出或最坏执行时间的实测保证。

## 盲区处理与观测器

低调制度和扇区边界无法自然提供两个足够长的窗口。本例扩展有效矢量，把实际施加电压和期望值的差异有界地补到后续帧。零请求会交替测量矢量，不长期注入固定方向的直流电压；高调制度饱和时清除误差累积。观察器使用实际写入的 CCR 电压，而非未限幅命令。

**平均电压补偿不消除瞬时纹波。** 每个强制 10 µs 矢量可能在低电感电机内产生很大 ΔI≈V·Δt/L。所有窗口、母线、电流和参数都需要真实电机验证；硬件限流/关断仍然必要。

观察器用 `e = v − R·i − L·di/dt` 和 PLL，正转反电势关系为 `eα=-E·sinθ, eβ=E·cosθ`。输入电压按“前帧第二保持时刻至 reload 的尾部 + 本帧 reload 至第二保持时刻的头部”积分，并使用两次保持时刻之间的真实 dt 更新电感项、PLL 和 PI。第一样本也已预测到第二样本时刻，减少直接拼接两相带来的纹波误差。预测仍依赖正确 R/L 和反电势，理想积分未包括实际死区、MOS 压降、模拟建立/保持误差，不能把主机模型结果当作真实锁相验证。

开环切换需要连续满足反电势幅值、PLL 残差、正向速度、强制角/速度一致性；达到固定时间不会直接冒充闭环。开环阶段使用旋转 Id 电流，使空载转子跟随强制 d 轴。接管时平滑取消角偏差和 Id，并立即由 100 Hz 速度 PI 给出受限 Iq，避免过渡阶段持续注入满启动转矩。失败有启动超时，运行后有失锁、失速和超速检测。

## 初始参数与保护边界

- 已记录线间 R=6700 mΩ、静态 L=1750 µH；平衡等效星形模型分别除以 2，得到相 R=3350 mΩ、L≈875 µH。相模型不是把线间值原样填入，也不代表动态 Ld/Lq 已测得。
- 在 `src/config.rs` 中用 `BATTERY_SERIES_CELLS` 明确选择 2 或 3，默认 2S，适用于当前 8 V 台架调试。欠压门限为串数 × `CELL_UNDERVOLTAGE_MV`，后者默认 3300 mV：2S 为 6.6 V，3S 为 9.9 V。测量值低于门限才锁存 6 号故障；启动前 RTT 打印所配置的串数和门限。切换实际电池串数前应修改配置并重新构建；没有自动识别或欠压降档。
- 单节 3.3 V 是沿用原 2S 6.6 V 的实验起点，须按电芯规格、负载压降和测量误差确认。软件只测总母线，不能发现单节失衡，也不代替 BMS。16 V 实验过压限制保持不变；这些门限不代表板子额定电压。
- 原理图的 EG2163 VCC 接 Q7 输出的“12V”网，+5V 接 LDO5 输出；母线欠压配置不能证明驱动在该低压下正常工作。必须实测 VCC、5V 和门极波形，确认驱动和 MOS 管满足实际低压工作条件。
- 对齐 Id=150 mA，旋转电流启动 Id=200 mA/Iq=0，速度环 Iq≤250 mA，软件跳闸 750 mA；都需要按实际电机/功率器件确认，750 mA 不是已知额定电流。
- 按 50 Hz 名义电流环带宽计算：Kp=L·2πf≈0.2749 mV/mA，Ki（每 8 kHz 帧）=R·2πf/8000≈0.13155 mV/mA，对应 Q15 的 9008/4311；实际两帧控制延迟、逆变器非理想和参数误差仍需整定。
- VDDA 合理性 4.5–5.5 V；ADC1 48 MHz 的手册允许条件为 VDDA≥3.3 V，但本板按 5 V 设计，采用更保守门限。
- 外加对称 1 µs 死区、AOE=0、OSSI/OSSR=1、OIS/OISN=0；故障关闭 MOE，保留输出强制低配置。EG2163 的典型内部死区不能替代整板测量。
- 首个有效电流样本超过门限、ADC 接近电源轨、偏置不合理、母线越界、采样失效、驱动故障、超时和控制超预算都锁存关闭。ADC 模拟看门狗也是离散采样保护，不是连续硬件急停。
- 原图没有已验证的独立过流 → ATIM BK 连接。本例未假装提供硬件短路保护，也没有实现 NTC 过温保护；必须有外部限流和断电措施。

## 构建

必须使用 release 优化构建；未优化的 debug 构建不满足本例的短中断预算，可能在未按启动输入前就触发时序故障。

在工作区根目录先生成可重建的 PAC/metadata，然后构建：

```sh
cargo run -p xtask -- regenerate
cargo build --release --target thumbv6m-none-eabi -p cw32-bldc-07-sensorless-foc
```

或在本目录执行 `cargo build --release`，继承板级目标配置。单 binary，无 lib、例程 feature、测试目录或 CI；源码包不包含外部验证脚本。

## 上板前必须完成的验证

1. 物理断开母线，上电不按启动输入，检查六个引脚/极性/复位状态，确认 PB0 零点约 2.5 V、VDDA/BGR/母线比例正确。
2. 低压限流台架、空载电机、独立断电/过流保护；确认实际 R/L、R0 功率、MOS 管额定值和驱动供电。不要对旋转中的电机执行本例低侧自举/对齐。
3. 示波器确认六路互补死区、两路内部事件对应的采样相位、模拟建立时间，以及两个有效矢量中的电流符号。源码的 2.5/10 µs 不是实测结果。
4. 测 ADC IRQ 到达延迟、第一样本 ISR 占用和第二样本控制总耗时。检查 `max_control_ticks` / `max_update_ticks` 只能辅助诊断，它们不包含完整异常入口/退出，也不证明 WCET。8 kHz 总帧为 12000 CPU tick。
5. 从小电流验证 Id/Iq 跟踪、参数/相序/转向，再验证有资格切换、失锁关断、过流/母线/漏采样/超预算/停止故障路径。不会因为“编译通过”省略这些步骤。

## 已发现的限制不是靠开关修复的

历史 10 kHz 版本采用 3.35 Ω/875 µH 相模型的 12 V 同轨迹仿真中，直接拼接两相的峰值误差约 120.4 mA、RMS 约 32.66 mA；增加预测/区间积分后，峰值约 14.7 mA、RMS 约 4.10 mA。这些只说明理想模型修正有效，不是 ADC 精度或实际板卡指标。

未测 R/L 时，电阻误差产生的 `ΔR × I` 可被电压模型当作反电势。早期锁转子、实际相电阻 2 Ω/配置 0.5 Ω 的模拟曾误进接管；采用线间测量值及后续启动修正不意味着任意未知电机的观测器偏差已经消除。低电感模型也出现过物理峰值先超过软件采样门限才被检测的情况，所以持续的硬件保护不能省略。

依据：用户提供的 `BLDC_SCH.pdf`（实际 R0=10 mΩ），[CW32L012 RM1.4](https://www.whxy.com/uploads/files/20260603/CW32L012_UserManual_CN_V1.4.pdf) §§17.3、17.10、25.4、25.12，以及 EG2163 官方数据手册。完整构建与外部数学检查结果见 [验证记录](../../../docs/validation-sensorless-foc.md)。

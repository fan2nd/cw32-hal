# 07：单电阻无感 FOC（独立实验例程）

面向 CW32L012C8 电机板，实际 R0 为 **10 mΩ**，覆盖原理图的 2 mΩ 标注。01–06 仍是独立的六步例程，07 不导入它们的业务源码。

本例包含电流重建、Clarke/Park、Id/Iq PI、双可测窗口调制、反电势模型和 PLL，以及有资格门槛的 OpenLoop → Blend → ClosedLoop。**新版尚未实板验证，不是通用电机即插即用固件。** 用户测得任意两根引线间 R=6.7 Ω、静态 L=1.75 mH，暂用平衡等效星形相模型 3.35 Ω/875 µH；这不证明动态 Ld/Lq、极对数、磁链或额定值。不能保证空载/带载启动成功，更不支持零速有载无感闭环。

## 默认行为与保护

- 普通 release 构建包含功率输出和有资格无感接管，无额外功能门。上电六个输出保持低；首次 ADC2/BGR/VDDA 合格后才累计零点样本，校准后等待手动启动，不自动转动。
- PA3 连续释放 60 ms 后再保持低 60 ms，切换启动/停止。原图 PA3 是 MCU_VF/VSR/ESC 输入，并非已标注按键；实验时先断开原电位器/PWM 输入。此软件开关不是独立急停。
- 启动经过低侧自举、对齐、旋转 Id 电流启动。反电势幅值、PLL 残差、正向速度、强制角/速度一致性连续达标才接管；没有固定延时冒充闭环。
- 故障锁存到 MCU 复位，按键不会自动重试。停止请求仍在下一次真实 reload 关桥。不要对旋转电机执行本例自举/对齐。
- 默认 2S，欠压 6.6 V；在 config.rs 明确选 3S 时为 9.9 V。不自动识别电池，不在欠压时降档。16 V 过压限制、150/200/250 mA 对齐/启动/运行限值及 750 mA 软件跳闸均保留。
- 3.3 V/节是实验起点，不是对未知电芯的安全结论，也不能发现单节失衡或代替 BMS。电池门限不证明 EG2163 VCC、LDO5 或 MOS 门极供电合格。
- 每个已解锁 ADC 样本立即检查电源轨、原始过流门限和离散模拟看门狗。两个 mA 换算共用采样时 VDDA，并在 ADC2 更新比例前完成。重建后再检查相电流。供电异常在进入 RL 加权运算前关断，Off/Calibrating 仍允许未接母线。
- 外加对称 1 µs 死区、AOE=0、OSSI/OSSR=1、OIS/OISN=0。故障先关 MOE、停 ATIM 及 ADC 触发，再禁用高频 IRQ。没有已验证的独立过流→ATIM BK 连线或过温保护，必须保留外部限流和断电措施。

## 本版为何改为 4 kHz

上一版 8 kHz EAU 台架记录 `site=4 start=4096 observed=1000 reload=true elapsed_min=8904 stage=5`。该次控制可用 7304 tick，却至少消耗 8904 tick；最差合法采样位置只有 5822 tick。故障在首次 Align 计算，实际帧仍为 Bootstrap，尚未包括正常电流运输和 OpenLoop 观测器，不能只削掉约 1600 tick 就宣称预算充足。

本版同时处理调度、数学和代码生成成本：

1. PWM/控制为 4 kHz，每帧 24000 tick。保留 700 tick reload 截止、128 tick 采样容差、960 tick 双窗口和距下一帧 600 tick 的控制退出余量。
2. 所有三相占空比共同平移，使最小比较值固定为 DUTY_MIN。相间电压和有效矢量时长不变，采样尽量提前；真实零矢量位置仍纳入观测模型。
3. 采用实际 PWM 边沿的指数加权 RL 模型，同时修正首样本到第二保持时刻的电流运输。旧端点电流梯形近似在降低频率时会误估电阻压降，不能只改 ARR 和增益。
4. 启动时通过窄 FLASH HAL 接口使能预取/缓存，带 KEY 写入并回读。96 MHz 必需的三等待周期不变；07 永久保留 FLASH 单例、不执行擦写，01–06 不启用此新接口。启动日志显示修改前状态。
5. EAU 的内部操作描述内联到一个共享热入口，消除原两层函数及 Operation/Result 搬运，避免各调用点复制故障关断代码。标称 dt 和严格 KCL 的恒等运算直接返回；有符号常量 32768 除法由编译器生成精确移位运算。没有软件除法回退或近似母线倒数。

Flash 缓存命中、总线等待和芯片乘法延迟没有实板 WCET 证明。指令数减少、模型通过和更大的安排时隙都不是台架达标证明；运行时 deadline 仍负责失败关断。

## 定时、采样与帧身份

96 MHz，ATIM PSC=0、ARR=23999、RCR=0，边沿对齐 PWM1 CH1–3；内部 PWM2 CH4/5 通过 MMS2=26 触发 ADC1。ADC1 ENS=0/CONT=0，单槽 CH8，每次触发仅一次转换；ADC=PCLK/2=48 MHz，70 周期采样+15 周期转换。保持时刻为触发后 140 tick，EOS 为 170 tick。

- 死区 96 tick；下降沿后等待 240 tick；有效矢量至少 960 tick（10 µs）。240+170+128=538 tick，小于窗口。每个样本分别检查时刻、顺序和 UIF，不能凭一个 EOS 假定没有覆盖。
- 比较值范围 2400–12000；初始比较值 [2400,3360,4320]，触发 [2640,3600]，接受读数区间 [2810,2938]、[3770,3898]。
- 预载/解锁必须 CNT≤700，控制全部完成必须 CNT<23400。最晚合法第二样本读取为 11578，保留 11822 tick（约 123.1 µs）；这是最坏采样位置的安排预算，不是已测耗时。最小窗口初始帧则有 19502 tick 可用。
- 最早下降沿为 2400，触发 2640，EOS 2810，均晚于原 reload 截止。首次启桥作用于三相 CCR=0 的 Bootstrap 帧，随后 FOC 通过真实 reload 切换。
- 五路 CCR 均预载：reload 先将旧 staged 晋升为 active，再将 pending 写入预载。ADC 只使用 active 的相序/波形；新计算仅进入 pending。禁止运行时 UG/UDIS 拼凑更新。
- ATIM/ADC1 同为 P0，不嵌套，EAU 只由 ADC1 使用。没有让原共享状态跨 reload 继续计算，也没有额外消息队列。命令约两帧流水线延迟，4 kHz 时为 500 µs。
- ADC2 上电先启动一次，此后每 1 ms（4 帧）发起；3 ms（12 帧）未更新即故障。仅初次就绪前且 MOE、软件解锁状态及全部流水线计划均为关闭时，允许无效 BGR/VDDA 在同一 3 ms 预算内重采样；无效值不刷新帧龄、不参与零点校准。工厂标定无效立即故障，首次合格后的 BGR/VDDA 异常也立即故障。速度环 100 Hz（40 帧），诊断内存每 50 ms（200 帧）。零点 2048 样本，约 256 ms。

## RL 观测与参数

两个电流样本分别对应首降相的负电流和末降相的正电流。首降相在两次保持之间先受 -2Vbus/3，再受 -Vbus/3；使用这两个真实区间、配置的 R/L 和上一轮反电势作指数运输，最后由 KCL 得第三相。

RlInterval 显式包含 dt、a=exp(-R·dt/L) 和指数加权电压响应 W。每段导通 [s,e] 对 W 的贡献为 Vbus·[exp(-R(T-e)/L)−exp(-R(T-s)/L)]，分别积分前帧尾部及本帧头部，再转为 αβ。观察器按 e=[W+R(a·i0−i1)]/(1−a) 逆解，不再把端点电流平均当区间电流平均。模型假定区间内反电势近似恒定；PLL 相位补偿使用指数权重的时间重心。

衰减表由配置 R/L 在编译期计算，运行时仅 Q15 查表/线性插值，没有浮点或运行时宽整数除法。参数校验约束中间乘积范围；修改 R/L、频率或保护上限后必须重新验证，不能仅通过编译判断模型有效。

50 Hz 名义电流环采用 Q15 Kp/Ki=9008/8622；PLL=10240/100。反电势滤波为 18/64，近似保持原 8 kHz 的物理时间常数；电流爬升 2 mA/帧仍为 8 A/s。自举、对齐、启动超时、资格、失锁、失速和混合时长按 CONTROL_HZ 保持原物理时间。没有放宽 30° 接管角、反电势资格、启动超时或电流保护来使模型通过。

强制可测窗口与较低 PWM 频率仍产生瞬时电流纹波。实际死区、管压降、模拟建立、采样偏差、参数误差和磁饱和不在理想模型中，软件观测器不能代替标定或硬件保护。

## LED 与首故障日志

PC13 常亮表示软件已解锁，熄灭表示未解锁；不能证明转子转动或门极安全。故障每闪亮/灭各 200 ms，整组后额外灭 1.6 s。闪码：1 参数、2 校准、3 样本无效、4 样本/慢 ADC 超时、5 过流、6 欠压、7 过压、8 失锁、9 启动超时、10 失速、11 超速、12 驱动、13 时序、14 EAU 算术错误。

标准 defmt-rtt 非阻塞输出仅在启动前和首故障关桥停触发后进行；高频 ISR 不打印。保留完整 `07 fault`、`ADC`、`TIMING`、`CONTROL` 和可能的 `CAL`、`EAU error` 行。RTT 缓冲区满可能丢日志。

- CAL reason：1 零点越界，2 噪声超限，3 工厂标定无效，4 BGR 原始值为零，5 计算 VDDA 超出 4.5–5.5 V，6 就绪前输出未全部关闭。raw_bus/raw_bgr 是 ADC2 原始值，factory_mv 是工厂半字，candidate_vdda 是此次计算值；首行 vdda 仍为上次已接受值或上电名义 5000，不能用它替代 candidate。ready 表示已经有过有效供电样本，samples/min/max 用于区分零点校准；原始母线饱和仍立即过压关断。
- ADC reason：1 跨 reload，2 多余样本，3 过早，4 过晚，0 其他。entry 是入口 CNT，read 是 RESULT0 读取/确认后的 CNT；保护检查 read，不用更早 entry 放宽判定。
- TIMING site：1 reload 入口、2 预载完成、3 解锁末尾、4 第二样本分段检查、5 输入 dt。合法 dt 为 12000–36000 tick。state_before 是故障前状态：0 校准、1 Off、2 Bootstrap、3 Align、4 OpenLoop、5 Blend、6 ClosedLoop、7 Fault。
- CONTROL 五段依次为电流/供电换算、错时重建、RL 区间、电流控制/观察器、调制/计划/诊断。last 是本帧，max 只包含通过截止的段；故障段可能只是下界，未执行后续段为 0。
- UIF 无法计数多个周期，elapsed_min 只给保守下界；不要按 u16 的 65536 回绕计算 PWM 周期。max_control/max_update 不包含完整异常入口/退出，不能当 WCET。
- EAU 检查 BUSY/ZERO/OVR，每次最多 64 次状态读取。任何错误在返回占位值前立即关 MOE、停 ATIM，然后锁存 14；不继续提交计划。错误子码 1 除零、2 溢出、3 忙、4 轮询超时、5 零预算。

具名 FOC_DIAGNOSTICS 可供调试器读取，但须先物理断开功率再 halt；CPU 暂停时 PWM 可能继续运行，不能带功率靠断点排故。

## 硬件映射与量纲

| 用途 | 映射 |
|---|---|
| 三相上桥 | PB5/PB6/PB7，ATIM CH1/2/3，AF7 |
| 三相下桥 | PA15/PB3/PB4，ATIM CH1N/2N/3N，AF7 |
| 快速母线电流 | PA6 OPA1 INP2、PA7 INN2，PB0 OPA 输出/ADC1 CH8 |
| 母线电压 | PA8，ADC2 CH5，10 kΩ/1 kΩ 分压 |
| 参考电压 | ADC2 CH15/BGR，工厂校准半字 0x001007D2 |
| 运行输入/LED | PA3/PC13 |

R17/R18=1 kΩ、R19=10 kΩ、R20/R21=20 kΩ，理想输出 2.5 V+10×Vshunt。实际 10 mΩ 对应约 100 mV/A，5 V/12 bit 约 12.2 mA/LSB；正电流从桥低端 IS 经 R0 流向 GND。VDDA 允许 4.5–5.5 V。PB2 慢平均电流和 PA0/1/2 六步相电压不参与本例闭环。R0 功率、MOS 型号和板子额定值尚未确认。

## 构建与台架验收

必须 release 构建；源码不附测试目录、额外 example feature 或 CI。工作区根目录执行：

```sh
cargo run -p xtask -- regenerate
cargo build --release --target thumbv6m-none-eabi -p cw32-bldc-07-sensorless-foc
```

1. 断开功率，检查复位/引脚极性、PB0 零点、BGR/VDDA/母线比例；确认启动日志 Flash wait=3 且预取/缓存回读已启用。
2. 使用低压限流、空载电机和独立断电保护，确认驱动 VCC、5 V、MOS 门极、死区、双采样位置与电流符号。
3. 测量完整中断延迟和首样本占用；覆盖 Align、OpenLoop、Blend、ClosedLoop、速度环/ADC2/诊断重合帧及限幅路径，不能只看 Align 成功或历史最大值。
4. 验证 Id/Iq、方向、资格接管以及停止/失锁/过流/电压/漏采样/超预算关断。不能用“编译或模型通过”替代实板验收。

外部定点/开关机械模型和 ARM 构建结果见[验证记录](../../../docs/validation-sensorless-foc.md)。依据包括用户 BLDC_SCH.pdf、[CW32L012 RM1.4](https://www.whxy.com/uploads/files/20260603/CW32L012_UserManual_CN_V1.4.pdf) §§4、7、11、17、25 和 EG2163 官方数据手册。
